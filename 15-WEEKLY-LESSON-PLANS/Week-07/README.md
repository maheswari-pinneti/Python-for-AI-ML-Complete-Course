> **Phase:** Phase 2 – Intermediate Python  
> **Duration:** 6 Days (1 Hour / Day = 6 Hours Total)  
> **Course Framework:** 144 Hours – Python for AI/ML Complete Course  

---

## 📌 Weekly Overview

Welcome to **Week 07** of the **Python for AI/ML** curriculum. In this module, students focus on **Object-Oriented Programming** within **Phase 2 – Intermediate Python**. The curriculum is structured with a progressive 6-day daily pedagogy: starting with conceptual grounding, moving to syntax and coding, exploring practical examples, deepening through advanced concepts and real-world applications, and culminating in hands-on exercises and weekly assessment on Day 6.

## 📖 Detailed Daily Lesson Plans

### 🗓️ Day 1: Introduction to OOP, Classes and Objects
- **Teaching Approach:** `Concepts and theory`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Paradigm shift: Procedural vs Object-Oriented Programming
  - Class as a blueprint and object as an instance in memory
  - The `class` keyword and basic instantiation
  - The `self` parameter: understanding instance binding
- **Hands-on / Practical Implementation:**
  - Conceptual walkthrough with architectural whiteboard / markdown notes, live code demonstration of primary concepts, and Q&A on fundamental principles.

### 🗓️ Day 2: Constructors, Attributes and Methods
- **Teaching Approach:** `Syntax and coding`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - The initializer method: `__init__()`
  - Instance variables vs class (static) variables
  - Instance methods, `@classmethod`, and `@staticmethod`
  - Dunder / Magic methods: `__str__()`, `__repr__()`, `__len__()`
- **Hands-on / Practical Implementation:**
  - Live coding session in VS Code / Jupyter Notebook demonstrating exact syntax, common error handling, and core code execution.

### 🗓️ Day 3: Inheritance and Types of Inheritance
- **Teaching Approach:** `Practical examples`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Single inheritance, multiple inheritance, and multi-level inheritance
  - The `super()` function and calling parent constructors
  - Method Resolution Order (MRO) and `C3` linearization algorithm
  - Building hierarchical model classes (e.g. `BaseModel` -> `LinearModel`)
- **Hands-on / Practical Implementation:**
  - Step-by-step practical coding of realistic scenarios, comparative examples, and interactive coding exercises for students.

### 🗓️ Day 4: Polymorphism and Method Overriding
- **Teaching Approach:** `Advanced concepts`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Polymorphism in Python and 'duck typing' principle
  - Overriding parent methods in child classes
  - Operator overloading using special methods: `__add__`, `__eq__`, `__lt__`
  - Abstract Base Classes (ABCs) using `abc.ABC` and `@abstractmethod`
- **Hands-on / Practical Implementation:**
  - Deep dive into inner mechanics, optimization techniques, edge cases, and best practice design patterns.

### 🗓️ Day 5: Encapsulation and Abstraction
- **Teaching Approach:** `Real-world applications`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Data hiding conventions: public, protected (`_var`), and private (`__var`) attributes
  - Name mangling mechanism in Python
  - Property decorators: `@property`, `@<name>.setter`, `@<name>.deleter`
  - Real-world application: Building a robust ML Experiment Tracker class
- **Hands-on / Practical Implementation:**
  - End-to-end implementation of an industry-relevant mini-project or case study showing how these skills power AI/ML pipelines.

### 🗓️ Day 6: OOP Practical Programs and Mini Project
- **Teaching Approach:** `Exercises, assignments and weekly assessment`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Design patterns: Factory pattern, Singleton pattern basics
  - Mini Project: Build an Object-Oriented Banking or Library Management System
  - Refactoring procedural code into clean OOP architecture
  - Weekly assessment: OOP architecture design challenge and assessment rubric
- **Hands-on / Practical Implementation:**
  - Guided lab review, live troubleshooting of assignment problems, timed coding challenge, and weekly assessment grading.

## 🎯 Weekly Assessment & Deliverables (Day 6)

At the conclusion of **Week 07**, each student is required to complete and submit the following:
1. **Coding Exercises:** Complete all daily coding tasks and store them in the respective practice files.
2. **Weekly Assessment Challenge:** Complete the designated practical assignment on **Object-Oriented Programming**.
3. **Code Quality Review:** Ensure code adheres to PEP 8 standards, includes clean comments, and avoids anti-patterns.
4. **Knowledge Check:** Complete the short theoretical evaluation covering key terminology and design decisions.
