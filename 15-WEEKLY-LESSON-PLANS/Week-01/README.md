# Week 01 – Introduction to Python

> **Phase:** Phase 1 – Python Fundamentals  
> **Duration:** 6 Days (1 Hour / Day = 6 Hours Total)  
> **Course Framework:** 144 Hours – Python for AI/ML Complete Course  

---

## 📌 Weekly Overview

Welcome to **Week 01** of the **Python for AI/ML** curriculum. In this module, students focus on **Introduction to Python** within **Phase 1 – Python Fundamentals**. The curriculum is structured with a progressive 6-day daily pedagogy: starting with conceptual grounding, moving to syntax and coding, exploring practical examples, deepening through advanced concepts and real-world applications, and culminating in hands-on exercises and weekly assessment on Day 6.

## 📖 Detailed Daily Lesson Plans

### 🗓️ Day 1: Introduction to Programming, What is Python?, Features and Applications
- **Teaching Approach:** `Concepts and theory`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - What is computer programming and high-level vs low-level languages
  - History, philosophy (Zen of Python), and why Python dominates AI/ML
  - Key features: interpreted, dynamically typed, cross-platform, extensive standard library
  - Applications across Data Science, AI, Web Development, Automation, and Scripting
- **Hands-on / Practical Implementation:**
  - Conceptual walkthrough with architectural whiteboard / markdown notes, live code demonstration of primary concepts, and Q&A on fundamental principles.

### 🗓️ Day 2: Python Installation, VS Code, Jupyter Notebook and Google Colab
- **Teaching Approach:** `Syntax and coding`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Installing Python 3.x and setting up system PATH
  - Setting up Visual Studio Code with the Python extension
  - Introduction to Jupyter Notebook and interactive computing
  - Getting started with Google Colab: cloud GPUs, cells, and file management
- **Hands-on / Practical Implementation:**
  - Live coding session in VS Code / Jupyter Notebook demonstrating exact syntax, common error handling, and core code execution.

### 🗓️ Day 3: Python Syntax, Comments, Indentation and First Python Program
- **Teaching Approach:** `Practical examples`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Basic syntax rules and writing `hello_world.py`
  - Understanding Python's indentation rules (PEP 8 standard)
  - Single-line (`#`) and multi-line docstring comments (`'''` / `"""`)
  - The `print()` function: `sep`, `end`, and formatted output basics
- **Hands-on / Practical Implementation:**
  - Step-by-step practical coding of realistic scenarios, comparative examples, and interactive coding exercises for students.

### 🗓️ Day 4: Variables, Naming Rules and Constants
- **Teaching Approach:** `Advanced concepts`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Variable declaration, assignment, and memory references (object IDs)
  - PEP 8 naming conventions (snake_case, CONSTANT_CASE, PascalCase)
  - Python keywords and forbidden identifiers (`keyword.kwlist`)
  - Multiple assignments and variable swapping idioms (`a, b = b, a`)
- **Hands-on / Practical Implementation:**
  - Deep dive into inner mechanics, optimization techniques, edge cases, and best practice design patterns.

### 🗓️ Day 5: Data Types: Integer, Float, String and Boolean
- **Teaching Approach:** `Real-world applications`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Core scalar data types: `int`, `float`, `str`, `bool`
  - Numeric operations, precision, scientific notation (`1e-4`)
  - Boolean logic: `True`, `False`, and truthiness of values
  - Handling user input via `input()` and interactive console prompts
- **Hands-on / Practical Implementation:**
  - End-to-end implementation of an industry-relevant mini-project or case study showing how these skills power AI/ML pipelines.

### 🗓️ Day 6: Type Checking, Type Conversion and Basic Practice Programs
- **Teaching Approach:** `Exercises, assignments and weekly assessment`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Checking types using `type()` and `isinstance()`
  - Implicit vs explicit type conversion (`int()`, `float()`, `str()`, `bool()`)
  - Common conversion pitfalls (e.g. converting non-numeric strings)
  - Weekly assessment: 5 coding exercises, 1 mini-calculator project, quiz
- **Hands-on / Practical Implementation:**
  - Guided lab review, live troubleshooting of assignment problems, timed coding challenge, and weekly assessment grading.

---

## 🎯 Weekly Assessment & Deliverables (Day 6)

At the conclusion of **Week 01**, each student is required to complete and submit the following:
1. **Coding Exercises:** Complete all daily coding tasks and store them in the respective practice files.
2. **Weekly Assessment Challenge:** Complete the designated practical assignment on **Introduction to Python**.
3. **Code Quality Review:** Ensure code adheres to PEP 8 standards, includes clean comments, and avoids anti-patterns.
4. **Knowledge Check:** Complete the short theoretical evaluation covering key terminology and design decisions.

## 💡 Pedagogical Notes for Instructors

> **Important Guidance:** This is part of an intensive 144-hour curriculum. Prioritize student progress, keyboard time, and hands-on coding capability over pure passive theory. Ensure every student types out the code and sees it execute successfully.
