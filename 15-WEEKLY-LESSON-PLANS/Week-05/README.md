# Week 05 – Functions and Functional Programming

> **Phase:** Phase 2 – Intermediate Python  
> **Duration:** 6 Days (1 Hour / Day = 6 Hours Total)  
> **Course Framework:** 144 Hours – Python for AI/ML Complete Course  

---

## 📌 Weekly Overview

Welcome to **Week 05** of the **Python for AI/ML** curriculum. In this module, students focus on **Functions and Functional Programming** within **Phase 2 – Intermediate Python**. The curriculum is structured with a progressive 6-day daily pedagogy: starting with conceptual grounding, moving to syntax and coding, exploring practical examples, deepening through advanced concepts and real-world applications, and culminating in hands-on exercises and weekly assessment on Day 6.

## 📖 Detailed Daily Lesson Plans

### 🗓️ Day 1: Introduction to Functions and Function Definition
- **Teaching Approach:** `Concepts and theory`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Modularity, DRY (Don't Repeat Yourself) principle, and abstraction
  - Function definition syntax with `def` keyword
  - Function invocation, execution stack, and docstrings (PEP 257)
  - Function type hints and annotations (`def func(x: int) -> int:`)
- **Hands-on / Practical Implementation:**
  - Conceptual walkthrough with architectural whiteboard / markdown notes, live code demonstration of primary concepts, and Q&A on fundamental principles.

### 🗓️ Day 2: Parameters, Arguments and Return Values
- **Teaching Approach:** `Syntax and coding`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Positional parameters vs positional arguments
  - Single return values vs multiple return values (tuple packing)
  - Function execution termination via `return` vs implicit `None`
  - Pass-by-object-reference: mutable vs immutable argument behavior
- **Hands-on / Practical Implementation:**
  - Live coding session in VS Code / Jupyter Notebook demonstrating exact syntax, common error handling, and core code execution.

### 🗓️ Day 3: Default, Keyword and Variable-Length Arguments
- **Teaching Approach:** `Practical examples`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Default argument values and the mutable default argument trap (`def f(x=[])`)
  - Keyword arguments and keyword-only arguments (`*`)
  - Arbitrary positional arguments: `*args`
  - Arbitrary keyword arguments: `**kwargs` and combining all argument types
- **Hands-on / Practical Implementation:**
  - Step-by-step practical coding of realistic scenarios, comparative examples, and interactive coding exercises for students.

### 🗓️ Day 4: Lambda Functions and Anonymous Functions
- **Teaching Approach:** `Advanced concepts`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Lambda syntax: `lambda arguments: expression`
  - When to use lambda functions vs named `def` functions
  - Higher-order functions: `map()`, `filter()`, `reduce()` (from `functools`)
  - Using lambda functions as custom sorting keys in `.sort()` and `sorted()`
- **Hands-on / Practical Implementation:**
  - Deep dive into inner mechanics, optimization techniques, edge cases, and best practice design patterns.

### 🗓️ Day 5: Recursion, Local and Global Scope
- **Teaching Approach:** `Real-world applications`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Variable scope and LEGB rule (Local, Enclosing, Global, Built-in)
  - The `global` and `nonlocal` keywords and best practices
  - Recursive functions: base case and recursive step
  - Classic recursion problems: Factorial, Fibonacci, and Directory tree traversal
- **Hands-on / Practical Implementation:**
  - End-to-end implementation of an industry-relevant mini-project or case study showing how these skills power AI/ML pipelines.

### 🗓️ Day 6: List Comprehensions and Function-Based Programs
- **Teaching Approach:** `Exercises, assignments and weekly assessment`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Advanced list, dictionary, and set comprehensions with nested conditions
  - Building modular functional pipelines for data transformation
  - Practical program: Text processing and feature extraction tool
  - Weekly assessment: 5 functional programming exercises, unit test suite
- **Hands-on / Practical Implementation:**
  - Guided lab review, live troubleshooting of assignment problems, timed coding challenge, and weekly assessment grading.

## 🎯 Weekly Assessment & Deliverables (Day 6)

At the conclusion of **Week 05**, each student is required to complete and submit the following:
1. **Coding Exercises:** Complete all daily coding tasks and store them in the respective practice files.
2. **Weekly Assessment Challenge:** Complete the designated practical assignment on **Functions and Functional Programming**.
3. **Code Quality Review:** Ensure code adheres to PEP 8 standards, includes clean comments, and avoids anti-patterns.
4. **Knowledge Check:** Complete the short theoretical evaluation covering key terminology and design decisions.
