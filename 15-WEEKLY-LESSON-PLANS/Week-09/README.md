## 📖 Detailed Daily Lesson Plans

### 🗓️ Day 1: Introduction to Probability
- **Teaching Approach:** `Concepts and theory`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Sample space, outcomes, events, and probability axioms
  - Theoretical vs empirical probability, Law of Large Numbers
  - Independent vs mutually exclusive (disjoint) events
  - Addition rule and multiplication rule of probability
- **Hands-on / Practical Implementation:**
  - Conceptual walkthrough with architectural whiteboard / markdown notes, live code demonstration of primary concepts, and Q&A on fundamental principles.

### 🗓️ Day 2: Conditional Probability and Bayes' Theorem
- **Teaching Approach:** `Syntax and coding`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Conditional probability formula: $P(A|B) = \frac{P(A \cap B)}{P(B)}$
  - Derivation and intuition of Bayes' Theorem: Prior, Likelihood, Posterior, Evidence
  - Applications in spam filtering, medical diagnostics, and classification
  - Coding a simple Bayesian probability calculator in Python
- **Hands-on / Practical Implementation:**
  - Live coding session in VS Code / Jupyter Notebook demonstrating exact syntax, common error handling, and core code execution.

### 🗓️ Day 3: Probability Distributions and Normal Distribution
- **Teaching Approach:** `Practical examples`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Random variables: Discrete vs Continuous
  - Discrete distributions: Bernoulli, Binomial, Poisson
  - Continuous distributions: Uniform, Normal (Gaussian) distribution
  - The 68-95-99.7 empirical rule, Z-scores, and standard normal distribution
- **Hands-on / Practical Implementation:**
  - Step-by-step practical coding of realistic scenarios, comparative examples, and interactive coding exercises for students.

### 🗓️ Day 4: Introduction to Calculus and Differentiation
- **Teaching Approach:** `Advanced concepts`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Rate of change, slopes of curves, and secant vs tangent lines
  - Definition of derivative as a limit: $f'(x) = \lim_{h \to 0} \frac{f(x+h)-f(x)}{h}$
  - Basic differentiation rules: Power rule, Constant multiple rule, Sum rule
  - Product rule, Quotient rule, and the Chain Rule
- **Hands-on / Practical Implementation:**
  - Deep dive into inner mechanics, optimization techniques, edge cases, and best practice design patterns.

### 🗓️ Day 5: Derivatives, Partial Derivatives and Gradients
- **Teaching Approach:** `Real-world applications`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Functions of multiple variables: $f(x, y)$ or $f(\mathbf{w})$
  - Partial derivatives ($rac{\partial f}{\partial x}$, $\frac{\partial f}{\partial y}$)
  - The Gradient vector ($\nabla f$): direction of steepest ascent
  - Calculating loss surface gradients in linear regression
- **Hands-on / Practical Implementation:**
  - End-to-end implementation of an industry-relevant mini-project or case study showing how these skills power AI/ML pipelines.

### 🗓️ Day 6: Gradient Descent and Mathematical Practice
- **Teaching Approach:** `Exercises, assignments and weekly assessment`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Gradient Descent optimization algorithm: update rule $w := w - \alpha \frac{\partial L}{\partial w}$
  - Role of learning rate $\alpha$ (overshooting vs slow convergence)
  - Implementing 1D and 2D Gradient Descent from scratch in Python
  - Weekly assessment: Calculus and probability problem set, code implementation
- **Hands-on / Practical Implementation:**
  - Guided lab review, live troubleshooting of assignment problems, timed coding challenge, and weekly assessment grading.
