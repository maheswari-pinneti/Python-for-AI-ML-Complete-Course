# Week 03 – Loops and Strings

> **Phase:** Phase 1 – Python Fundamentals  
> **Duration:** 6 Days (1 Hour / Day = 6 Hours Total)  
> **Course Framework:** 144 Hours – Python for AI/ML Complete Course  

---

## 📌 Weekly Overview

Welcome to **Week 03** of the **Python for AI/ML** curriculum. In this module, students focus on **Loops and Strings** within **Phase 1 – Python Fundamentals**. The curriculum is structured with a progressive 6-day daily pedagogy: starting with conceptual grounding, moving to syntax and coding, exploring practical examples, deepening through advanced concepts and real-world applications, and culminating in hands-on exercises and weekly assessment on Day 6.

## 📖 Detailed Daily Lesson Plans

### 🗓️ Day 1: Introduction to Loops and For Loop
- **Teaching Approach:** `Concepts and theory`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Concept of iteration and repetition in algorithms
  - Syntax of `for` loop and iterating through sequences
  - The `range()` function: `start`, `stop`, `step` parameters
  - Summation, factorials, and counting occurrences
- **Hands-on / Practical Implementation:**
  - Conceptual walkthrough with architectural whiteboard / markdown notes, live code demonstration of primary concepts, and Q&A on fundamental principles.

### 🗓️ Day 2: While Loop and Loop Control
- **Teaching Approach:** `Syntax and coding`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Syntax and condition checking of `while` loop
  - Preventing infinite loops and maintaining loop invariant counters
  - Simulating interactive menus and user-driven termination loops
  - `while ... else` construct and when to apply it
- **Hands-on / Practical Implementation:**
  - Live coding session in VS Code / Jupyter Notebook demonstrating exact syntax, common error handling, and core code execution.

### 🗓️ Day 3: Break, Continue, Pass and Nested Loops
- **Teaching Approach:** `Practical examples`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - `break` statement: early termination of loops
  - `continue` statement: skipping iterations
  - `pass` statement: placeholder for syntactical completeness
  - Nested loops: 2D grids, multiplication tables, pattern printing (stars, numbers)
- **Hands-on / Practical Implementation:**
  - Step-by-step practical coding of realistic scenarios, comparative examples, and interactive coding exercises for students.

### 🗓️ Day 4: Introduction to Strings and String Indexing
- **Teaching Approach:** `Advanced concepts`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Strings as immutable sequences of characters
  - Positive indexing (0 to n-1) and negative indexing (-1 to -n)
  - String length with `len()` and `IndexError` prevention
  - String concatenation, repetition, and escape sequences
- **Hands-on / Practical Implementation:**
  - Deep dive into inner mechanics, optimization techniques, edge cases, and best practice design patterns.

### 🗓️ Day 5: String Slicing and String Methods
- **Teaching Approach:** `Real-world applications`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - String slicing syntax: `string[start:stop:step]` and string reversal (`[::-1]`)
  - Case manipulation: `.lower()`, `.upper()`, `.title()`, `.capitalize()`
  - Search & replace: `.find()`, `.index()`, `.replace()`, `.count()`
  - Whitespace and formatting: `.strip()`, `.split()`, `.join()`, and f-strings
- **Hands-on / Practical Implementation:**
  - End-to-end implementation of an industry-relevant mini-project or case study showing how these skills power AI/ML pipelines.

### 🗓️ Day 6: String and Loop-Based Practice Programs
- **Teaching Approach:** `Exercises, assignments and weekly assessment`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Palindrome verification and anagram checker
  - Vowel/consonant counter and word frequency analyzer
  - Password strength validator using loop conditions
  - Weekly assessment: 5 coding challenges covering loops and string algorithms
- **Hands-on / Practical Implementation:**
  - Guided lab review, live troubleshooting of assignment problems, timed coding challenge, and weekly assessment grading.

## 🎯 Weekly Assessment & Deliverables (Day 6)

At the conclusion of **Week 03**, each student is required to complete and submit the following:
1. **Coding Exercises:** Complete all daily coding tasks and store them in the respective practice files.
2. **Weekly Assessment Challenge:** Complete the designated practical assignment on **Loops and Strings**.
3. **Code Quality Review:** Ensure code adheres to PEP 8 standards, includes clean comments, and avoids anti-patterns.
4. **Knowledge Check:** Complete the short theoretical evaluation covering key terminology and design decisions.
