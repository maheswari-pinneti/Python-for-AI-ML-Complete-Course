## 📖 Detailed Daily Lesson Plans

### 🗓️ Day 1: Introduction to Embeddings
- **Teaching Approach:** `Concepts and theory`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - What are vector embeddings? Converting semantic meaning into numeric coordinate space
  - Embedding models (e.g. OpenAI text-embedding-3, Gemini text-embedding-004, BGE)
  - Measuring semantic similarity: Cosine similarity vs Euclidean distance vs Dot product
  - Generating text embeddings in Python using modern embedding APIs
- **Hands-on / Practical Implementation:**
  - Conceptual walkthrough with architectural whiteboard / markdown notes, live code demonstration of primary concepts, and Q&A on fundamental principles.

### 🗓️ Day 2: Vector Databases and Similarity Search
- **Teaching Approach:** `Syntax and coding`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Why vector databases are required for high-dimensional nearest-neighbor search
  - Overview of vector databases: ChromaDB, FAISS, Pinecone, Qdrant, Weaviate
  - Setting up local vector store using ChromaDB or FAISS in Python
  - Creating collections, upserting documents with metadata, and querying by vector similarity
- **Hands-on / Practical Implementation:**
  - Live coding session in VS Code / Jupyter Notebook demonstrating exact syntax, common error handling, and core code execution.

### 🗓️ Day 3: Introduction to LangChain
- **Teaching Approach:** `Practical examples`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - What is LangChain and the LLM application orchestration ecosystem
  - Core LangChain primitives: PromptTemplates, ChatModels, OutputParsers
  - LangChain Expression Language (LCEL): chaining components with the pipe `|` operator
  - Memory components and document loaders (`PyPDFLoader`, `TextLoader`)
- **Hands-on / Practical Implementation:**
  - Step-by-step practical coding of realistic scenarios, comparative examples, and interactive coding exercises for students.

### 🗓️ Day 4: Retrieval-Augmented Generation (RAG)
- **Teaching Approach:** `Advanced concepts`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Why RAG is essential: overcoming LLM hallucinations and knowledge cutoff limitations
  - The standard RAG pipeline: Ingestion -> Chunking -> Embedding -> Storage -> Retrieval -> Generation
  - Chunking strategies: fixed size, sliding window, recursive character splitter, semantic chunking
  - Building an end-to-end RAG chain: retrieving context and injecting into the prompt
- **Hands-on / Practical Implementation:**
  - Deep dive into inner mechanics, optimization techniques, edge cases, and best practice design patterns.

### 🗓️ Day 5: AI Agents and Tool Calling
- **Teaching Approach:** `Real-world applications`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - What is an AI Agent? Autonomous reasoning, planning, and action loops
  - The ReAct framework (Reason + Act)
  - Tool calling / Function calling: enabling LLMs to invoke external Python functions and APIs
  - Building an agent with search, math calculator, and database query capabilities
- **Hands-on / Practical Implementation:**
  - End-to-end implementation of an industry-relevant mini-project or case study showing how these skills power AI/ML pipelines.

### 🗓️ Day 6: Build a Document-Based AI Assistant
- **Teaching Approach:** `Exercises, assignments and weekly assessment`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Capstone mini-project: Build a 'Chat with your PDF/Docs' assistant using RAG
  - Ingesting custom documents, chunking, creating Chroma vector store, and running conversational Q&A
  - Evaluating retrieval accuracy and response faithfulness
  - Weekly assessment: Functional RAG application submission and code review
- **Hands-on / Practical Implementation:**
  - Guided lab review, live troubleshooting of assignment problems, timed coding challenge, and weekly assessment grading.

## 🎯 Weekly Assessment & Deliverables (Day 6)

At the conclusion of **Week 22**, each student is required to complete and submit the following:
1. **Coding Exercises:** Complete all daily coding tasks and store them in the respective practice files.
2. **Weekly Assessment Challenge:** Complete the designated practical assignment on **RAG, Embeddings and AI Agents**.
3. **Code Quality Review:** Ensure code adheres to PEP 8 standards, includes clean comments, and avoids anti-patterns.
4. **Knowledge Check:** Complete the short theoretical evaluation covering key terminology and design decisions.
