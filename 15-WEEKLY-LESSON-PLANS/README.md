# 📚 Python for AI/ML – 24 Weeks Daily Teaching Plan

## ⏱️ Course Structure (144 Hours)

| Attribute | Specification |
| :--- | :--- |
| **Course Duration** | 24 Weeks |
| **Classes per Week** | 6 Days |
| **Daily Class** | 1 Hour |
| **Weekly Total** | 6 Hours |
| **Total Curriculum** | 144 Hours |

---

## 🔄 Teaching and Assessment Pattern

Every week adheres to this consistent 6-day instructional pedagogy:

| Day | Teaching Approach | Description |
| :--- | :--- | :--- |
| **Day 1** | Concepts and theory | Intuition, fundamental architecture, and mental models |
| **Day 2** | Syntax and coding | Core Python/library syntax, keywords, and signature patterns |
| **Day 3** | Practical examples | Guided hands-on implementations and step-by-step code |
| **Day 4** | Advanced concepts | Edge cases, optimization, inner mechanics, and deep dives |
| **Day 5** | Real-world applications | Industry use cases, pipelines, and applied mini-projects |
| **Day 6** | Exercises, assignments and weekly assessment | Problem-solving labs, coding challenges, and weekly tests |
