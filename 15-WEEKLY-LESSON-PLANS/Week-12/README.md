## 📌 Weekly Overview

Welcome to **Week 12** of the **Python for AI/ML** curriculum. In this module, students focus on **Data Visualization and EDA** within **Phase 4 – Data Analytics and Data Science**. The curriculum is structured with a progressive 6-day daily pedagogy: starting with conceptual grounding, moving to syntax and coding, exploring practical examples, deepening through advanced concepts and real-world applications, and culminating in hands-on exercises and weekly assessment on Day 6.

## 📖 Detailed Daily Lesson Plans

### 🗓️ Day 1: Introduction to Data Visualization
- **Teaching Approach:** `Concepts and theory`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Why data visualization is critical for data analysis and storytelling
  - Choosing the right chart for data types: categorical vs continuous
  - Visual encoding: position, length, area, angle, color, and shape
  - Setting up visualization libraries: `matplotlib.pyplot` and `seaborn`
- **Hands-on / Practical Implementation:**
  - Conceptual walkthrough with architectural whiteboard / markdown notes, live code demonstration of primary concepts, and Q&A on fundamental principles.

### 🗓️ Day 2: Matplotlib: Line, Bar and Scatter Charts
- **Teaching Approach:** `Syntax and coding`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Matplotlib figure and axes anatomy (`fig, ax = plt.subplots()`)
  - Line plots for trends and time series (`plt.plot()`)
  - Bar charts (vertical `plt.bar()`, horizontal `plt.barh()`)
  - Scatter plots for bivariate relationship analysis (`plt.scatter()`)
- **Hands-on / Practical Implementation:**
  - Live coding session in VS Code / Jupyter Notebook demonstrating exact syntax, common error handling, and core code execution.

### 🗓️ Day 3: Histograms, Pie Charts and Customization
- **Teaching Approach:** `Practical examples`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Histograms for frequency distributions and binning (`plt.hist()`)
  - Box plots for five-number summaries and outlier visualization (`plt.boxplot()`)
  - Formatting: titles, x/y labels, legends, grid lines, ticks, and color palettes
  - Saving high-resolution publication charts: `plt.savefig('chart.png', dpi=300)`
- **Hands-on / Practical Implementation:**
  - Step-by-step practical coding of realistic scenarios, comparative examples, and interactive coding exercises for students.

### 🗓️ Day 4: Seaborn: Statistical Visualization
- **Teaching Approach:** `Advanced concepts`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Seaborn themes, styles (`sns.set_theme()`), and built-in datasets
  - Distribution plots: `sns.histplot()`, `sns.kdeplot()` (Kernel Density Estimation)
  - Categorical plots: `sns.barplot()`, `sns.countplot()`, `sns.boxplot()`, `sns.violinplot()`
  - Relational & matrix plots: `sns.scatterplot()`, `sns.pairplot()`, `sns.heatmap()` with correlation matrix
- **Hands-on / Practical Implementation:**
  - Deep dive into inner mechanics, optimization techniques, edge cases, and best practice design patterns.

### 🗓️ Day 5: Exploratory Data Analysis and Data Cleaning
- **Teaching Approach:** `Real-world applications`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Systematic EDA workflow: Univariate, Bivariate, and Multivariate analysis
  - Checking skewness, kurtosis, distributions, and variance
  - Detecting multicollinearity using correlation heatmaps
  - Transforming skewed features (log transform, square root transform)
- **Hands-on / Practical Implementation:**
  - End-to-end implementation of an industry-relevant mini-project or case study showing how these skills power AI/ML pipelines.

### 🗓️ Day 6: Complete EDA Mini Project
- **Teaching Approach:** `Exercises, assignments and weekly assessment`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Executing an end-to-end Exploratory Data Analysis report on an unseen dataset
  - Formulating analytical hypotheses and validating them visually
  - Writing executive insights and data-driven recommendations
  - Weekly assessment: Submission of an EDA Jupyter notebook with rubric evaluation
- **Hands-on / Practical Implementation:**
  - Guided lab review, live troubleshooting of assignment problems, timed coding challenge, and weekly assessment grading.

## 🎯 Weekly Assessment & Deliverables (Day 6)

At the conclusion of **Week 12**, each student is required to complete and submit the following:
1. **Coding Exercises:** Complete all daily coding tasks and store them in the respective practice files.
2. **Weekly Assessment Challenge:** Complete the designated practical assignment on **Data Visualization and EDA**.
3. **Code Quality Review:** Ensure code adheres to PEP 8 standards, includes clean comments, and avoids anti-patterns.
4. **Knowledge Check:** Complete the short theoretical evaluation covering key terminology and design decisions.
