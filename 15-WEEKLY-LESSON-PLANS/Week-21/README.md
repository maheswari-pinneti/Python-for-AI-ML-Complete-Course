## 📌 Weekly Overview

Welcome to **Week 21** of the **Python for AI/ML** curriculum. In this module, students focus on **Generative AI and Large Language Models** within **Phase 8 – Generative AI and LLM**. The curriculum is structured with a progressive 6-day daily pedagogy: starting with conceptual grounding, moving to syntax and coding, exploring practical examples, deepening through advanced concepts and real-world applications, and culminating in hands-on exercises and weekly assessment on Day 6.

## 📖 Detailed Daily Lesson Plans

### 🗓️ Day 1: Introduction to Generative AI
- **Teaching Approach:** `Concepts and theory`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Discriminative AI vs Generative AI models
  - Modality overview: Text (LLMs), Image (Diffusion models), Audio, Video, Multimodal
  - History and evolution of natural language processing: N-grams, Word2Vec, Seq2Seq to Transformers
  - The Generative AI stack: foundation models, fine-tuning, RAG, and application orchestration
- **Hands-on / Practical Implementation:**
  - Conceptual walkthrough with architectural whiteboard / markdown notes, live code demonstration of primary concepts, and Q&A on fundamental principles.

### 🗓️ Day 2: Large Language Models and Their Applications
- **Teaching Approach:** `Syntax and coding`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - What is a Large Language Model (LLM)? Scale, parameters, and emergent capabilities
  - Major LLM families: GPT (OpenAI), Claude (Anthropic), Gemini (Google), Llama (Meta)
  - Pre-training (next-token prediction) -> Supervised Fine-Tuning (SFT) -> RLHF / DPO alignment
  - Enterprise use cases: summarization, generation, translation, extraction, code synthesis
- **Hands-on / Practical Implementation:**
  - Live coding session in VS Code / Jupyter Notebook demonstrating exact syntax, common error handling, and core code execution.

### 🗓️ Day 3: Transformer Architecture
- **Teaching Approach:** `Practical examples`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - The landmark paper: 'Attention Is All You Need' (Vaswani et al., 2017)
  - Encoder-only (BERT), Decoder-only (GPT), and Encoder-Decoder (T5) architectures
  - Input embeddings and Positional Encoding (why order matters)
  - Multi-Head Self-Attention, Feed-Forward networks, and Residual connections
- **Hands-on / Practical Implementation:**
  - Step-by-step practical coding of realistic scenarios, comparative examples, and interactive coding exercises for students.

### 🗓️ Day 4: Tokens, Tokenization and Attention Mechanism
- **Teaching Approach:** `Advanced concepts`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Tokenization algorithms: Byte-Pair Encoding (BPE), WordPiece, SentencePiece
  - Calculating token counts, context window limits, and token pricing
  - Self-Attention mathematical formulation: $\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$
  - Query, Key, and Value intuition explained clearly
- **Hands-on / Practical Implementation:**
  - Deep dive into inner mechanics, optimization techniques, edge cases, and best practice design patterns.

### 🗓️ Day 5: Prompt Engineering and LLM APIs
- **Teaching Approach:** `Real-world applications`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Prompt engineering techniques: Zero-shot, Few-shot, Chain-of-Thought (CoT), ReAct prompt structure
  - System prompts, user prompts, assistant context, and safety guardrails
  - Calling LLM APIs using Python (`openai`, `google-genai`, or `anthropic` SDK)
  - Configuring inference hyperparameters: `temperature`, `top_p`, `max_tokens`, `stop_sequences`
- **Hands-on / Practical Implementation:**
  - End-to-end implementation of an industry-relevant mini-project or case study showing how these skills power AI/ML pipelines.

### 🗓️ Day 6: Build a Basic AI Chatbot
- **Teaching Approach:** `Exercises, assignments and weekly assessment`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Developing an interactive CLI chatbot with persistent conversation memory
  - Managing chat history, token budgets, and context truncation
  - Adding system persona and custom formatting instructions
  - Weekly assessment: Prompt engineering challenge, working chatbot submission, and quiz
- **Hands-on / Practical Implementation:**
  - Guided lab review, live troubleshooting of assignment problems, timed coding challenge, and weekly assessment grading.

## 🎯 Weekly Assessment & Deliverables (Day 6)

At the conclusion of **Week 21**, each student is required to complete and submit the following:
1. **Coding Exercises:** Complete all daily coding tasks and store them in the respective practice files.
2. **Weekly Assessment Challenge:** Complete the designated practical assignment on **Generative AI and Large Language Models**.
3. **Code Quality Review:** Ensure code adheres to PEP 8 standards, includes clean comments, and avoids anti-patterns.
4. **Knowledge Check:** Complete the short theoretical evaluation covering key terminology and design decisions.
