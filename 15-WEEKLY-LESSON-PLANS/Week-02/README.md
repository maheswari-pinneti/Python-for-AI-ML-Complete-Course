> **Phase:** Phase 1 – Python Fundamentals

---

## 📌 Weekly Overview

Welcome to **Week 02** of the **Python for AI/ML** curriculum. In this module, students focus on **Operators and Conditional Statements** within **Phase 1 – Python Fundamentals**. The curriculum is structured with a progressive 6-day daily pedagogy: starting with conceptual grounding, moving to syntax and coding, exploring practical examples, deepening through advanced concepts and real-world applications, and culminating in hands-on exercises and weekly assessment on Day 6.

## 📖 Detailed Daily Lesson Plans

### 🗓️ Day 1: Arithmetic Operators
- **Teaching Approach:** `Concepts and theory`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Addition (`+`), Subtraction (`-`), Multiplication (`*`), Division (`/`)
  - Floor Division (`//`), Modulo (`%`), Exponentiation (`**`)
  - Integer division vs floating-point division semantics
  - Compound arithmetic operations and mathematical expressions
- **Hands-on / Practical Implementation:**
  - Conceptual walkthrough with architectural whiteboard / markdown notes, live code demonstration of primary concepts, and Q&A on fundamental principles.

### 🗓️ Day 2: Comparison and Assignment Operators
- **Teaching Approach:** `Syntax and coding`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Relational operators: `==`, `!=`, `>`, `<`, `>=`, `<=`
  - Chained comparisons (`10 < x <= 50`)
  - Assignment operators: `=`, `+=`, `-=`, `*=`, `/=`, `//=`, `%=`, `**=`
  - Identity operators: `is` vs `==` (identity vs equality)
- **Hands-on / Practical Implementation:**
  - Live coding session in VS Code / Jupyter Notebook demonstrating exact syntax, common error handling, and core code execution.

### 🗓️ Day 3: Logical, Bitwise and Membership Operators
- **Teaching Approach:** `Practical examples`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Logical operators: `and`, `or`, `not` with short-circuit evaluation
  - Bitwise operators: `&`, `|`, `^`, `~`, `<<`, `>>`
  - Membership operators: `in` and `not in` with sequences
  - Evaluating complex Boolean expressions and truth tables
- **Hands-on / Practical Implementation:**
  - Step-by-step practical coding of realistic scenarios, comparative examples, and interactive coding exercises for students.

### 🗓️ Day 4: Operator Precedence and Type Conversion Practice
- **Teaching Approach:** `Advanced concepts`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - PEMDAS / BODMAS in Python operator precedence order
  - Using parentheses for explicit evaluation clarity
  - Truthy and Falsy evaluations in logical expressions
  - Type casting within complex mathematical and logical expressions
- **Hands-on / Practical Implementation:**
  - Deep dive into inner mechanics, optimization techniques, edge cases, and best practice design patterns.

### 🗓️ Day 5: If, Elif and Else Statements
- **Teaching Approach:** `Real-world applications`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Decision making architecture in programming
  - Syntax and structure of `if`, `elif`, and `else` blocks
  - Ternary operator / conditional expressions (`x if condition else y`)
  - Real-world application: Grade calculator, ticket pricing logic, BMI classifier
- **Hands-on / Practical Implementation:**
  - End-to-end implementation of an industry-relevant mini-project or case study showing how these skills power AI/ML pipelines.

### 🗓️ Day 6: Nested Conditions and Conditional Practice Programs
- **Teaching Approach:** `Exercises, assignments and weekly assessment`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Nested `if-else` architectures and guard clauses
  - Refactoring nested conditionals to flat logic
  - Practice programs: Leap year checker, loan eligibility, quadrant identifier
  - Weekly assessment: 6 conditional algorithm tasks and problem-solving test
- **Hands-on / Practical Implementation:**
  - Guided lab review, live troubleshooting of assignment problems, timed coding challenge, and weekly assessment grading.

## 🎯 Weekly Assessment & Deliverables (Day 6)

At the conclusion of **Week 02**, each student is required to complete and submit the following:
1. **Coding Exercises:** Complete all daily coding tasks and store them in the respective practice files.
2. **Weekly Assessment Challenge:** Complete the designated practical assignment on **Operators and Conditional Statements**.
3. **Code Quality Review:** Ensure code adheres to PEP 8 standards, includes clean comments, and avoids anti-patterns.
4. **Knowledge Check:** Complete the short theoretical evaluation covering key terminology and design decisions.
