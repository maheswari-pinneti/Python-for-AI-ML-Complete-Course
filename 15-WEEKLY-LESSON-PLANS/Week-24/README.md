# Week 24 – End-to-End AI/ML Project

> **Phase:** Phase 10 – Final Capstone Project  
> **Duration:** 6 Days (1 Hour / Day = 6 Hours Total)  
> **Course Framework:** 144 Hours – Python for AI/ML Complete Course  

---

## 📌 Weekly Overview

Welcome to **Week 24** of the **Python for AI/ML** curriculum. In this module, students focus on **End-to-End AI/ML Project** within **Phase 10 – Final Capstone Project**. The curriculum is structured with a progressive 6-day daily pedagogy: starting with conceptual grounding, moving to syntax and coding, exploring practical examples, deepening through advanced concepts and real-world applications, and culminating in hands-on exercises and weekly assessment on Day 6.

## 📖 Detailed Daily Lesson Plans

### 🗓️ Day 1: Project Selection, Requirements and Dataset Collection
- **Teaching Approach:** `Concepts and theory`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Selecting a comprehensive capstone domain (e.g., Predictive Healthcare, Financial Fraud, E-Commerce Recommender, RAG Document Assistant)
  - Defining business objectives, target deliverables, KPIs, and success metrics
  - Dataset sourcing, validation, licensing, and setting up the project workspace repository
  - Creating project architecture blueprint and milestone roadmap
- **Hands-on / Practical Implementation:**
  - Conceptual walkthrough with architectural whiteboard / markdown notes, live code demonstration of primary concepts, and Q&A on fundamental principles.

### 🗓️ Day 2: Data Cleaning, Preprocessing and EDA
- **Teaching Approach:** `Syntax and coding`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Conducting rigorous exploratory data analysis on the project dataset
  - Handling missing values, anomalies, skewness, and outliers with automated scripts
  - Engineering robust domain features and scaling transformations
  - Exporting clean, versioned train/validation/test datasets
- **Hands-on / Practical Implementation:**
  - Live coding session in VS Code / Jupyter Notebook demonstrating exact syntax, common error handling, and core code execution.

### 🗓️ Day 3: Model Selection, Training and Evaluation
- **Teaching Approach:** `Practical examples`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Benchmarking multiple candidate algorithms (baseline models -> advanced models)
  - Performing rigorous cross-validation and hyperparameter optimization
  - Evaluating candidate models using domain-specific primary and secondary metrics
  - Selecting the champion model and analyzing feature importances and residuals
- **Hands-on / Practical Implementation:**
  - Step-by-step practical coding of realistic scenarios, comparative examples, and interactive coding exercises for students.

### 🗓️ Day 4: Model Optimization and API Development
- **Teaching Approach:** `Advanced concepts`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Serializing the finalized champion model and preprocessing pipeline
  - Developing production-ready FastAPI prediction backend with Pydantic validation
  - Writing automated unit tests for preprocessing and API endpoints using `pytest`
  - Benchmarking endpoint inference latency and optimizing memory footprint
- **Hands-on / Practical Implementation:**
  - Deep dive into inner mechanics, optimization techniques, edge cases, and best practice design patterns.

### 🗓️ Day 5: Frontend/Dashboard Integration and Deployment
- **Teaching Approach:** `Real-world applications`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Building an intuitive Streamlit frontend connected to the model API
  - Implementing user input forms, batch file uploads, and interactive prediction visualizations
  - Containerizing the complete application with Docker
  - Deploying the live interactive system to cloud hosting (e.g. Hugging Face Spaces / Render)
- **Hands-on / Practical Implementation:**
  - End-to-end implementation of an industry-relevant mini-project or case study showing how these skills power AI/ML pipelines.

### 🗓️ Day 6: Final Testing, Documentation and Project Presentation
- **Teaching Approach:** `Exercises, assignments and weekly assessment`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Writing professional project documentation: comprehensive `README.md`, API docs, architecture diagram
  - Preparing executive slide presentation and 5-minute project video walkthrough
  - Final capstone evaluation: grading rubric on code quality, architecture, metrics, and delivery
  - Course completion debrief, next steps, portfolio guidance, and interview readiness
- **Hands-on / Practical Implementation:**
  - Guided lab review, live troubleshooting of assignment problems, timed coding challenge, and weekly assessment grading.

---

## 🎯 Weekly Assessment & Deliverables (Day 6)

At the conclusion of **Week 24**, each student is required to complete and submit the following:
1. **Coding Exercises:** Complete all daily coding tasks and store them in the respective practice files.
2. **Weekly Assessment Challenge:** Complete the designated practical assignment on **End-to-End AI/ML Project**.
3. **Code Quality Review:** Ensure code adheres to PEP 8 standards, includes clean comments, and avoids anti-patterns.
4. **Knowledge Check:** Complete the short theoretical evaluation covering key terminology and design decisions.

## 💡 Pedagogical Notes for Instructors

> **Important Guidance:** This is part of an intensive 144-hour curriculum. Prioritize student progress, keyboard time, and hands-on coding capability over pure passive theory. Ensure every student types out the code and sees it execute successfully.
