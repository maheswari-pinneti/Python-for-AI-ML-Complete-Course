## 📌 Weekly Overview

Welcome to **Week 15** of the **Python for AI/ML** curriculum. In this module, students focus on **Classification Algorithms** within **Phase 5 – Machine Learning Fundamentals**. The curriculum is structured with a progressive 6-day daily pedagogy: starting with conceptual grounding, moving to syntax and coding, exploring practical examples, deepening through advanced concepts and real-world applications, and culminating in hands-on exercises and weekly assessment on Day 6.

## 📖 Detailed Daily Lesson Plans

### 🗓️ Day 1: Introduction to Classification
- **Teaching Approach:** `Concepts and theory`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Binary classification vs Multi-class vs Multi-label classification
  - Decision boundaries and geometric separation in feature space
  - Overview of prominent classification algorithms and their inductive biases
  - Evaluating classification predictions beyond raw accuracy
- **Hands-on / Practical Implementation:**
  - Conceptual walkthrough with architectural whiteboard / markdown notes, live code demonstration of primary concepts, and Q&A on fundamental principles.

### 🗓️ Day 2: Decision Tree Algorithm
- **Teaching Approach:** `Syntax and coding`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - How Decision Trees split data recursively: nodes, branches, leaves
  - Splitting criteria: Gini Impurity vs Information Gain / Shannon Entropy
  - Training `DecisionTreeClassifier` with Scikit-learn
  - Controlling tree depth: `max_depth`, `min_samples_split`, `min_samples_leaf` to prevent overfitting
- **Hands-on / Practical Implementation:**
  - Live coding session in VS Code / Jupyter Notebook demonstrating exact syntax, common error handling, and core code execution.

### 🗓️ Day 3: Random Forest Algorithm
- **Teaching Approach:** `Practical examples`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Ensemble methods concept: Wisdom of the Crowd
  - Bagging (Bootstrap Aggregating) and random feature subspace selection
  - Training `RandomForestClassifier` and hyperparameter configuration (`n_estimators`)
  - Extracting feature importances (`model.feature_importances_`) and visualization
- **Hands-on / Practical Implementation:**
  - Step-by-step practical coding of realistic scenarios, comparative examples, and interactive coding exercises for students.

### 🗓️ Day 4: K-Nearest Neighbors (KNN)
- **Teaching Approach:** `Advanced concepts`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Instance-based lazy learning: no explicit training phase
  - Distance metrics: Euclidean, Manhattan, Minkowski distance
  - Choosing the optimal value of $k$: bias-variance trade-off
  - Crucial role of feature scaling (StandardScaler) for distance-based algorithms
- **Hands-on / Practical Implementation:**
  - Deep dive into inner mechanics, optimization techniques, edge cases, and best practice design patterns.

### 🗓️ Day 5: Naive Bayes and Support Vector Machines
- **Teaching Approach:** `Real-world applications`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Naive Bayes classifier: applying Bayes theorem with conditional independence assumption
  - GaussianNB, MultinomialNB (text classification), and BernoulliNB
  - Support Vector Machines (SVM): maximum margin hyperplanes, support vectors
  - Kernel trick: Linear, Polynomial, and RBF (Radial Basis Function) kernels
- **Hands-on / Practical Implementation:**
  - End-to-end implementation of an industry-relevant mini-project or case study showing how these skills power AI/ML pipelines.

### 🗓️ Day 6: Classification Model Practical Project
- **Teaching Approach:** `Exercises, assignments and weekly assessment`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Comparing Decision Tree, Random Forest, KNN, and SVM on a real-world classification dataset
  - Model benchmarking: training speed, prediction accuracy, and confusion matrix
  - Selecting the best model for production deployment
  - Weekly assessment: Classification project notebook and theoretical test
- **Hands-on / Practical Implementation:**
  - Guided lab review, live troubleshooting of assignment problems, timed coding challenge, and weekly assessment grading.

## 🎯 Weekly Assessment & Deliverables (Day 6)

At the conclusion of **Week 15**, each student is required to complete and submit the following:
1. **Coding Exercises:** Complete all daily coding tasks and store them in the respective practice files.
2. **Weekly Assessment Challenge:** Complete the designated practical assignment on **Classification Algorithms**.
3. **Code Quality Review:** Ensure code adheres to PEP 8 standards, includes clean comments, and avoids anti-patterns.
4. **Knowledge Check:** Complete the short theoretical evaluation covering key terminology and design decisions.
