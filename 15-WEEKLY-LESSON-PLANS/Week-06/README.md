## 📌 Weekly Overview

Welcome to **Week 06** of the **Python for AI/ML** curriculum. In this module, students focus on **Modules, Files and Exception Handling** within **Phase 2 – Intermediate Python**. The curriculum is structured with a progressive 6-day daily pedagogy: starting with conceptual grounding, moving to syntax and coding, exploring practical examples, deepening through advanced concepts and real-world applications, and culminating in hands-on exercises and weekly assessment on Day 6.

## 📖 Detailed Daily Lesson Plans

### 🗓️ Day 1: Modules, Import Statements and Built-in Modules
- **Teaching Approach:** `Concepts and theory`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Understanding Python modules (`.py` files) and the `sys.path` search order
  - Import syntax variations: `import math`, `from math import sqrt`, `import numpy as np`
  - Exploring built-in standard modules: `math`, `random`, `datetime`, `os`, `sys`
  - The `if __name__ == '__main__':` boilerplate and module execution guard
- **Hands-on / Practical Implementation:**
  - Conceptual walkthrough with architectural whiteboard / markdown notes, live code demonstration of primary concepts, and Q&A on fundamental principles.

### 🗓️ Day 2: Packages, pip and Virtual Environments
- **Teaching Approach:** `Syntax and coding`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Creating packages with directories and `__init__.py`
  - Package manager: `pip install`, `pip list`, `pip freeze > requirements.txt`
  - Virtual environments with `venv`: `python -m venv .venv` and activation
  - Why isolated environments matter for AI/ML package dependencies
- **Hands-on / Practical Implementation:**
  - Live coding session in VS Code / Jupyter Notebook demonstrating exact syntax, common error handling, and core code execution.

### 🗓️ Day 3: Exception Handling: Try, Except, Else and Finally
- **Teaching Approach:** `Practical examples`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Syntax errors vs runtime exceptions
  - The `try ... except ... else ... finally` control flow
  - Handling specific exceptions: `ValueError`, `KeyError`, `FileNotFoundError`, `ZeroDivisionError`
  - Raising custom exceptions with `raise` and creating custom exception classes
- **Hands-on / Practical Implementation:**
  - Step-by-step practical coding of realistic scenarios, comparative examples, and interactive coding exercises for students.

### 🗓️ Day 4: File Handling: Read, Write and Append
- **Teaching Approach:** `Advanced concepts`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - File opening modes: `'r'`, `'w'`, `'a'`, `'r+'`, `'rb'`, `'wb'`
  - Reading files: `.read()`, `.readline()`, `.readlines()`, and iterating over file objects
  - Context managers and the `with open(...) as f:` construct
  - Character encoding: UTF-8, handling file paths with `pathlib.Path`
- **Hands-on / Practical Implementation:**
  - Deep dive into inner mechanics, optimization techniques, edge cases, and best practice design patterns.

### 🗓️ Day 5: JSON, CSV and Working with Data Files
- **Teaching Approach:** `Real-world applications`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Working with tabular CSV data using the built-in `csv` module (`reader`, `DictReader`)
  - Working with JSON: `json.load()`, `json.loads()`, `json.dump()`, `json.dumps()`
  - Parsing nested JSON responses from REST APIs
  - Sanitizing and saving structured data logs
- **Hands-on / Practical Implementation:**
  - End-to-end implementation of an industry-relevant mini-project or case study showing how these skills power AI/ML pipelines.

### 🗓️ Day 6: Debugging and File Handling Practical Programs
- **Teaching Approach:** `Exercises, assignments and weekly assessment`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Debugging tools: Python debugger `pdb`, VS Code breakpoints, stack trace inspection
  - Real-world application: Building a student dataset file logger and parser
  - Handling file corruption and I/O edge cases cleanly
  - Weekly assessment: 4 file/exception processing tasks and code review
- **Hands-on / Practical Implementation:**
  - Guided lab review, live troubleshooting of assignment problems, timed coding challenge, and weekly assessment grading.

## 🎯 Weekly Assessment & Deliverables (Day 6)

At the conclusion of **Week 06**, each student is required to complete and submit the following:
1. **Coding Exercises:** Complete all daily coding tasks and store them in the respective practice files.
2. **Weekly Assessment Challenge:** Complete the designated practical assignment on **Modules, Files and Exception Handling**.
3. **Code Quality Review:** Ensure code adheres to PEP 8 standards, includes clean comments, and avoids anti-patterns.
4. **Knowledge Check:** Complete the short theoretical evaluation covering key terminology and design decisions.
