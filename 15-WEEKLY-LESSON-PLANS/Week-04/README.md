# Week 04 – Python Data Structures

> **Phase:** Phase 1 – Python Fundamentals  
> **Duration:** 6 Days (1 Hour / Day = 6 Hours Total)  
> **Course Framework:** 144 Hours – Python for AI/ML Complete Course  

---

## 📌 Weekly Overview

Welcome to **Week 04** of the **Python for AI/ML** curriculum. In this module, students focus on **Python Data Structures** within **Phase 1 – Python Fundamentals**. The curriculum is structured with a progressive 6-day daily pedagogy: starting with conceptual grounding, moving to syntax and coding, exploring practical examples, deepening through advanced concepts and real-world applications, and culminating in hands-on exercises and weekly assessment on Day 6.

## 📖 Detailed Daily Lesson Plans

### 🗓️ Day 1: Lists: Creation, Indexing and Slicing
- **Teaching Approach:** `Concepts and theory`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Lists as ordered, mutable, heterogeneous collections
  - List creation: empty list, literal lists, and `list()` constructor
  - Indexing, multi-level indexing, and advanced slicing
  - Updating, mutating elements, and memory allocation of dynamic arrays
- **Hands-on / Practical Implementation:**
  - Conceptual walkthrough with architectural whiteboard / markdown notes, live code demonstration of primary concepts, and Q&A on fundamental principles.

### 🗓️ Day 2: List Methods, Operations and Comprehensions
- **Teaching Approach:** `Syntax and coding`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Adding elements: `.append()`, `.extend()`, `.insert()`
  - Removing elements: `.pop()`, `.remove()`, `clear()`, `del`
  - Searching and sorting: `.sort()`, `sorted()`, `.reverse()`, `.index()`
  - Introduction to basic list comprehensions: `[x for x in iterable]`
- **Hands-on / Practical Implementation:**
  - Live coding session in VS Code / Jupyter Notebook demonstrating exact syntax, common error handling, and core code execution.

### 🗓️ Day 3: Tuples and Tuple Operations
- **Teaching Approach:** `Practical examples`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Tuples as ordered, immutable collections: syntax and parentheses
  - Why use tuples: data integrity, hashability, dictionary keys, performance
  - Tuple packing, unpacking, and `*` wildcard unpacking (`a, *b, c`)
  - Common tuple operations, slicing, and methods (`.count()`, `.index()`)
- **Hands-on / Practical Implementation:**
  - Step-by-step practical coding of realistic scenarios, comparative examples, and interactive coding exercises for students.

### 🗓️ Day 4: Sets and Set Operations
- **Teaching Approach:** `Advanced concepts`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Sets as unordered, mutable collections of unique, hashable items
  - Set creation, `.add()`, `.remove()`, `.discard()`, and `.pop()`
  - Mathematical set operations: union (`|`), intersection (`&`), difference (`-`), symmetric difference (`^`)
  - Subsets, supersets, disjoint sets, and frozensets
- **Hands-on / Practical Implementation:**
  - Deep dive into inner mechanics, optimization techniques, edge cases, and best practice design patterns.

### 🗓️ Day 5: Dictionaries, Keys, Values and Methods
- **Teaching Approach:** `Real-world applications`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Dictionaries as key-value mappings (hash maps in Python)
  - Accessing, inserting, updating, and deleting key-value pairs
  - Dictionary methods: `.keys()`, `.values()`, `.items()`, `.get()`, `.update()`
  - Iterating through dictionaries and dictionary comprehensions
- **Hands-on / Practical Implementation:**
  - End-to-end implementation of an industry-relevant mini-project or case study showing how these skills power AI/ML pipelines.

### 🗓️ Day 6: Nested Data Structures and Practical Programs
- **Teaching Approach:** `Exercises, assignments and weekly assessment`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Lists of dictionaries (dataset records) and nested dictionary traversal
  - Flattening lists, removing duplicates while preserving order
  - Real-world data handling: building an in-memory student inventory system
  - Weekly assessment: Data structures coding challenge, test, and rubric
- **Hands-on / Practical Implementation:**
  - Guided lab review, live troubleshooting of assignment problems, timed coding challenge, and weekly assessment grading.

## 🎯 Weekly Assessment & Deliverables (Day 6)

At the conclusion of **Week 04**, each student is required to complete and submit the following:
1. **Coding Exercises:** Complete all daily coding tasks and store them in the respective practice files.
2. **Weekly Assessment Challenge:** Complete the designated practical assignment on **Python Data Structures**.
3. **Code Quality Review:** Ensure code adheres to PEP 8 standards, includes clean comments, and avoids anti-patterns.
4. **Knowledge Check:** Complete the short theoretical evaluation covering key terminology and design decisions.
