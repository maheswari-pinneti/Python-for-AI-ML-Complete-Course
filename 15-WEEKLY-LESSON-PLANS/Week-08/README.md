## 📌 Weekly Overview

Welcome to **Week 08** of the **Python for AI/ML** curriculum. In this module, students focus on **Linear Algebra and Statistics** within **Phase 3 – Mathematics for AI/ML**. The curriculum is structured with a progressive 6-day daily pedagogy: starting with conceptual grounding, moving to syntax and coding, exploring practical examples, deepening through advanced concepts and real-world applications, and culminating in hands-on exercises and weekly assessment on Day 6.

## 📖 Detailed Daily Lesson Plans

### 🗓️ Day 1: Introduction to Mathematics for AI/ML
- **Teaching Approach:** `Concepts and theory`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Why mathematics is the backbone of Machine Learning and Deep Learning
  - Overview of linear algebra, calculus, statistics, and probability in ML
  - How machine learning algorithms represent data as numbers and matrices
  - Setting up Python math libraries (`math`, `statistics`, `scipy`)
- **Hands-on / Practical Implementation:**
  - Conceptual walkthrough with architectural whiteboard / markdown notes, live code demonstration of primary concepts, and Q&A on fundamental principles.

### 🗓️ Day 2: Scalars, Vectors and Vector Operations
- **Teaching Approach:** `Syntax and coding`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Scalars (0D), Vectors (1D): magnitude, direction, geometric interpretation
  - Vector addition, scalar multiplication, and linear combinations
  - Dot product (inner product) and cosine similarity formula
  - Vector norms: $L_1$ norm (Manhattan) and $L_2$ norm (Euclidean)
- **Hands-on / Practical Implementation:**
  - Live coding session in VS Code / Jupyter Notebook demonstrating exact syntax, common error handling, and core code execution.

### 🗓️ Day 3: Matrices, Matrix Operations and Transpose
- **Teaching Approach:** `Practical examples`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Matrices as linear transformations and data tables (samples $\times$ features)
  - Matrix addition, scalar multiplication, and transpose ($A^T$)
  - Matrix multiplication ($A \times B$) dimensions rule and dot products
  - Identity matrix ($I$), diagonal matrix, symmetric matrix, and inverse ($A^{-1}$)
- **Hands-on / Practical Implementation:**
  - Step-by-step practical coding of realistic scenarios, comparative examples, and interactive coding exercises for students.

### 🗓️ Day 4: Mean, Median and Mode
- **Teaching Approach:** `Advanced concepts`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Measures of central tendency: Arithmetic Mean, Median, and Mode
  - Sensitivity of mean to outliers vs robustness of median
  - Weighted mean, geometric mean, and harmonic mean
  - Implementing central tendency calculations from scratch in Python
- **Hands-on / Practical Implementation:**
  - Deep dive into inner mechanics, optimization techniques, edge cases, and best practice design patterns.

### 🗓️ Day 5: Variance, Standard Deviation and Correlation
- **Teaching Approach:** `Real-world applications`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Measures of dispersion: Range, Interquartile Range (IQR)
  - Variance (sample vs population: Bessel's correction $N-1$)
  - Standard deviation ($\sigma$) and coefficient of variation
  - Covariance and Pearson correlation coefficient ($r$): positive, negative, zero
- **Hands-on / Practical Implementation:**
  - End-to-end implementation of an industry-relevant mini-project or case study showing how these skills power AI/ML pipelines.

### 🗓️ Day 6: Statistical Calculations Using Python
- **Teaching Approach:** `Exercises, assignments and weekly assessment`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Writing a complete statistical summary function without external packages
  - Detecting outliers using the $1.5 \times \text{IQR}$ rule
  - Analyzing correlation between variables in a real dataset
  - Weekly assessment: 6 math & stats programming problems and theory quiz
- **Hands-on / Practical Implementation:**
  - Guided lab review, live troubleshooting of assignment problems, timed coding challenge, and weekly assessment grading.

## 🎯 Weekly Assessment & Deliverables (Day 6)

At the conclusion of **Week 08**, each student is required to complete and submit the following:

3. **Code Quality Review:** Ensure code adheres to PEP 8 standards, includes clean comments, and avoids anti-patterns.
4. **Knowledge Check:** Complete the short theoretical evaluation covering key terminology and design decisions.
