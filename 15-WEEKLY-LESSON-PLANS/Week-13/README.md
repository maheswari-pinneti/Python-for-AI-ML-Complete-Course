## 📌 Weekly Overview

Welcome to **Week 13** of the **Python for AI/ML** curriculum. In this module, students focus on **Introduction to Artificial Intelligence and Machine Learning** within **Phase 5 – Machine Learning Fundamentals**. The curriculum is structured with a progressive 6-day daily pedagogy: starting with conceptual grounding, moving to syntax and coding, exploring practical examples, deepening through advanced concepts and real-world applications, and culminating in hands-on exercises and weekly assessment on Day 6.

## 📖 Detailed Daily Lesson Plans

### 🗓️ Day 1: Introduction to AI, ML and Deep Learning
- **Teaching Approach:** `Concepts and theory`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Defining Artificial Intelligence, Machine Learning, and Deep Learning (the hierarchy)
  - Traditional rule-based programming vs Machine Learning paradigm
  - Key AI breakthroughs, history, and modern enterprise landscape
  - Ethical considerations, bias, fairness, and safety in AI systems
- **Hands-on / Practical Implementation:**
  - Conceptual walkthrough with architectural whiteboard / markdown notes, live code demonstration of primary concepts, and Q&A on fundamental principles.

### 🗓️ Day 2: Types of Machine Learning
- **Teaching Approach:** `Syntax and coding`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Supervised Learning: predicting targets from labeled inputs
  - Unsupervised Learning: discovering hidden patterns in unlabeled data
  - Reinforcement Learning: agents, environment, state, action, and reward signals
  - Semi-supervised and self-supervised learning paradigms overview
- **Hands-on / Practical Implementation:**
  - Live coding session in VS Code / Jupyter Notebook demonstrating exact syntax, common error handling, and core code execution.

### 🗓️ Day 3: Supervised Learning
- **Teaching Approach:** `Practical examples`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Regression vs Classification tasks: continuous vs discrete targets
  - Supervised learning pipeline: data intake -> features -> model -> predictions -> evaluation
  - Common supervised use cases: spam detection, churn prediction, house price estimation
  - Mapping business problems to mathematical formulations
- **Hands-on / Practical Implementation:**
  - Step-by-step practical coding of realistic scenarios, comparative examples, and interactive coding exercises for students.

### 🗓️ Day 4: Unsupervised Learning
- **Teaching Approach:** `Advanced concepts`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Clustering: grouping similar instances without explicit labels
  - Dimensionality reduction: projecting high-dimensional data to lower dimensions
  - Anomaly detection: identifying outliers and fraud detection applications
  - Association rule learning (market basket analysis)
- **Hands-on / Practical Implementation:**
  - Deep dive into inner mechanics, optimization techniques, edge cases, and best practice design patterns.

### 🗓️ Day 5: Training Data, Testing Data, Features and Labels
- **Teaching Approach:** `Real-world applications`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Feature matrix ($X$) vs target vector ($y$)
  - The golden rule of ML: Never evaluate models on training data
  - Train/Test split: `train_test_split()` from `sklearn.model_selection`
  - Stratification, random states, and reproducibility in machine learning experiments
- **Hands-on / Practical Implementation:**
  - End-to-end implementation of an industry-relevant mini-project or case study showing how these skills power AI/ML pipelines.

### 🗓️ Day 6: First Machine Learning Model Using Scikit-learn
- **Teaching Approach:** `Exercises, assignments and weekly assessment`
- **Class Duration:** 1 Hour (60 minutes)
- **Key Topics Covered:**
  - Installing Scikit-learn (`pip install scikit-learn`)
  - The Scikit-learn API pattern: `fit()`, `predict()`, `score()`
  - Training your first end-to-end classifier (e.g. Iris classification)
  - Weekly assessment: 4 foundational ML questions and building a baseline model
- **Hands-on / Practical Implementation:**
  - Guided lab review, live troubleshooting of assignment problems, timed coding challenge, and weekly assessment grading.

## 🎯 Weekly Assessment & Deliverables (Day 6)

At the conclusion of **Week 13**, each student is required to complete and submit the following:
1. **Coding Exercises:** Complete all daily coding tasks and store them in the respective practice files.
2. **Weekly Assessment Challenge:** Complete the designated practical assignment on **Introduction to Artificial Intelligence and Machine Learning**.
3. **Code Quality Review:** Ensure code adheres to PEP 8 standards, includes clean comments, and avoids anti-patterns.
4. **Knowledge Check:** Complete the short theoretical evaluation covering key terminology and design decisions.

## 💡 Pedagogical Notes for Instructors

> **Important Guidance:** This is part of an intensive 144-hour curriculum. Prioritize student progress, keyboard time, and hands-on coding capability over pure passive theory. Ensure every student types out the code and sees it execute successfully.
