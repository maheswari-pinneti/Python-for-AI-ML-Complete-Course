## **157. Write Your First Algorithm**

### **Definition**

An algorithm is a finite sequence of clear and logical instructions used to solve a particular problem or complete a task.

An algorithm describes the steps required to solve a problem before converting those steps into a programming language.

Algorithms are independent of any particular programming language.

### **Characteristics of a Good Algorithm**

1. **Input:** It may accept zero or more inputs.
2. **Output:** It should produce at least one result.
3. **Definiteness:** Every instruction should be clear.
4. **Finiteness:** It must complete after a finite number of steps.
5. **Effectiveness:** Each step should be simple and executable.
6. **Correctness:** It should solve the intended problem.

### **Example 1: Algorithm to Add Two Numbers**

**Problem:**

Write an algorithm to accept two numbers and calculate their sum.

**Algorithm:**

1. Start.
2. Read the first number.
3. Read the second number.
4. Add the two numbers.
5. Store the result in a variable called `sum`.
6. Display the sum.
7. Stop.

**Example Input:**

```text
Enter first number: 10
Enter second number: 20
```

**Expected Output:**

```text
Sum = 30
```

**Python Program:**

```python
num1 = 10
num2 = 20

sum = num1 + num2

print("Sum:", sum)
```

**Output:**

```text
Sum: 30
```

### **Example 2: Algorithm to Find the Area of a Rectangle**

**Problem:**

Calculate the area of a rectangle using its length and width.

**Formula:**

```text
Area = Length × Width
```

**Algorithm:**

1. Start.
2. Read the length.
3. Read the width.
4. Multiply the length by the width.
5. Store the result in `area`.
6. Display the area.
7. Stop.

**Example Input:**

```text
Length = 10
Width = 5
```

**Expected Output:**

```text
Area = 50
```

**Python Program:**

```python
length = 10
width = 5

area = length * width

print("Area:", area)
```

### **Example 3: Algorithm to Check Whether a Number Is Even or Odd**

**Algorithm:**

1. Start.
2. Read a number.
3. Divide the number by 2 and calculate the remainder.
4. If the remainder is 0, display "Even Number".
5. Otherwise, display "Odd Number".
6. Stop.

**Python Program:**

```python
number = 10

if number % 2 == 0:
    print("Even Number")
else:
    print("Odd Number")
```

**Output:**

```text
Even Number
```

## **158. Create Your First Flowchart**

### **Definition**

A flowchart is a graphical representation of an algorithm or process using standardized symbols and arrows to show the sequence of operations.

It helps programmers understand how a program works before implementing it using a programming language.

### **Why Are Flowcharts Used?**

- To visualize program logic.
- To understand the sequence of operations.
- To identify decision-making conditions.
- To explain complex processes.
- To communicate ideas clearly.
- To identify possible logical errors.
- To simplify program development.

### **Common Flowchart Symbols**

| Symbol | Name | Purpose |
|---|---|---|
| Oval | Start / End | Indicates the beginning or end |
| Rectangle | Process | Represents calculations or operations |
| Parallelogram | Input / Output | Represents receiving or displaying information |
| Diamond | Decision | Represents a condition with possible outcomes |
| Arrow | Flow Line | Shows the direction of execution |
| Circle | Connector | Connects different parts of a flowchart |

### **Example 1: Flowchart to Add Two Numbers**

**Problem:**

Create a flowchart to add two numbers.

**Flowchart:**

```text
       ( START )
           |
           v
    / Input A, B /
           |
           v
    [ SUM = A + B ]
           |
           v
      / Display /
        SUM
           |
           v
        ( END )
```

**Explanation:**

1. Start the process.
2. Accept two numbers.
3. Add the numbers.
4. Display the result.
5. End the process.

**Example:**

```text
A = 10
B = 20

SUM = 10 + 20

Output = 30
```

### **Example 2: Flowchart to Check Even or Odd**

```text
   / Print Even /  / Print Odd /
```

**Explanation:**

- The program accepts a number.
- It checks whether the remainder after division by 2 is zero.

## **159. Write Your First Pseudocode**

### **Definition**

Pseudocode is an informal, structured way of describing the logic of a program using simple English and programming-like statements.

It helps programmers plan the solution without worrying about the exact syntax of a programming language.

Pseudocode is not directly executable by a computer.

### **Why Is Pseudocode Used?**

- To plan program logic.
- To understand a problem before coding.
- To explain an algorithm.
- To communicate solutions with other developers.
- To simplify complex programming problems.
- To convert problem-solving steps into actual code.

### **Common Pseudocode Keywords**

| Keyword | Purpose |
|---|---|
| START | Begins the algorithm |
| STOP / END | Ends the algorithm |
| INPUT / READ | Accepts information |
| OUTPUT / PRINT | Displays information |
| SET | Assigns a value |
| IF | Checks a condition |
| ELSE | Defines an alternative |
| END IF | Ends a conditional block |
| FOR | Repeats instructions a fixed number of times |
| WHILE | Repeats instructions while a condition is true |
| FUNCTION | Defines a reusable block of logic |
| RETURN | Sends a result back from a function |

### **Example 1: Pseudocode to Add Two Numbers**

**Problem:**

Calculate the sum of two numbers.

**Pseudocode:**

```text
START

INPUT number1
INPUT number2

SET sum = number1 + number2

OUTPUT sum

STOP
```

**Python Program:**

```python
number1 = int(input("Enter first number: "))
number2 = int(input("Enter second number: "))

sum = number1 + number2

print("Sum:", sum)
```

### **Example 2: Pseudocode to Check Voting Eligibility**

**Pseudocode:**

```text
START

INPUT age

IF age >= 18 THEN
    OUTPUT "Eligible to Vote"
ELSE
    OUTPUT "Not Eligible to Vote"
END IF

STOP
```

**Python Program:**

```python
age = int(input("Enter your age: "))

if age >= 18:
    print("Eligible to Vote")
else:
    print("Not Eligible to Vote")
```

### **Example 3: Pseudocode to Find the Largest of Three Numbers**

**Pseudocode:**

```text
START

INPUT A
INPUT B
INPUT C

IF A >= B AND A >= C THEN
    OUTPUT A
ELSE IF B >= A AND B >= C THEN
    OUTPUT B
ELSE
    OUTPUT C
END IF

STOP
```

**Python Program:**

```python
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))
c = int(input("Enter third number: "))

if a >= b and a >= c:
    print("Largest:", a)
elif b >= a and b >= c:
    print("Largest:", b)
else:
    print("Largest:", c)
```

## **161. Create a Real-World Problem-Solving Algorithm**

### **Definition**

### **Example: Online Food Ordering System**

**Problem Statement:**

Create an algorithm for ordering food through an online food delivery application.

**Requirements:**

- The customer should be able to select food.

- The system should calculate the total amount.
- The customer should be able to make payment.
- The system should confirm the order.

**Inputs:**

- Customer details.
- Selected food items.
- Food quantities.
- Delivery address.
- Payment method.

**Processing:**

- Verify customer information.
- Calculate the total price.
- Validate the delivery address.
- Process the payment.
- Create the order.

**Outputs:**

- Order confirmation.
- Total bill.
- Order ID.
- Delivery status.

### **Algorithm**

1. Start.
2. Open the food delivery application.
3. Select a restaurant.
4. Display available food items.
5. Select food items.
6. Add selected items to the cart.
7. Enter the delivery address.
8. Calculate the total amount.
9. Display the order summary.

### **Python Example: Simple Food Ordering System**

```python
menu = {
    "Pizza": 250,
    "Burger": 120,
    "Sandwich": 100
}

print("Food Menu:")
for item, price in menu.items():
    print(item, "-", price)

food = input("Select your food: ")

if food in menu:
    quantity = int(input("Enter quantity: "))

    if quantity > 0:
        total = menu[food] * quantity
        print("Food:", food)
        print("Quantity:", quantity)
        print("Total Amount:", total)
    else:
        print("Quantity must be greater than zero")
else:
    print("Food item not available")
```

**Example Output:**

```text

Sandwich - 100

Select your food: Pizza
Enter quantity: 2

Food: Pizza
Quantity: 2
Total Amount: 500
```

## **162. Analyze a Banking Transaction Process**

### **Definition**

A banking transaction process is a sequence of operations used to transfer, deposit, withdraw, or manage money through a banking system.

Programming is used to validate customers, verify balances, process transactions, update account records, and generate transaction confirmations.

### **Types of Banking Transactions**

1. Cash Deposit.
2. Cash Withdrawal.
3. Money Transfer.
4. Balance Enquiry.
5. Bill Payment.
6. Online Payment.
7. Loan Payment.

### **How a Banking Transaction Works**

Consider a customer withdrawing money from an ATM.

**Process:**

1. The customer inserts an ATM card.
2. The system reads the card details.
3. The customer enters the PIN.
4. The bank verifies the PIN.
5. The customer selects Cash Withdrawal.
6. The customer enters the withdrawal amount.
7. The system checks the account balance.
8. The system checks transaction limits and other applicable rules.
9. If the transaction is approved, the amount is deducted.
10. The ATM dispenses cash.
11. The transaction is recorded.
12. The customer receives confirmation.
13. The process ends.

### **Inputs and Outputs**

| Inputs | Outputs |
|---|---|
| ATM card details | Account verification result |
| PIN | Authentication result |
| Withdrawal amount | Transaction result |
| Account information | Updated account balance |
| Transaction details | Receipt or confirmation |

### **Algorithm for ATM Cash Withdrawal**

1. Start.
2. Insert the ATM card.
3. Enter the PIN.
4. Validate the PIN.
5. If the PIN is incorrect, display an error message and follow the bank's retry policy.
6. If the PIN is correct, display the banking menu.
7. Select Cash Withdrawal.
8. Enter the withdrawal amount.
9. Check the account balance.
10. Check applicable withdrawal limits.
11. If sufficient balance and all checks pass, process the withdrawal.
12. Otherwise, display an appropriate message.
13. Update the account balance after successful processing.
14. Generate a transaction confirmation.
15. Stop.

### **Python Example: Simple Banking Withdrawal**

```python
balance = 10000

amount = int(input("Enter withdrawal amount: "))

if amount <= 0:
    print("Enter a valid amount")

elif amount <= balance:
    balance = balance - amount

    print("Withdrawal Successful")
    print("Remaining Balance:", balance)

else:
    print("Insufficient Balance")
```

**Example Output:**

```text
Enter withdrawal amount: 2000

Withdrawal Successful
Remaining Balance: 8000
```

### **Real-World Programming Concepts Used**

- Variables.
- Conditional statements.
- Input validation.
- Arithmetic operations.
- Authentication.
- Database management.
- Transaction processing.
- Security.

**Note:**
This is only a simplified simulation of a withdrawal. Real banking systems require secure authentication, transaction authorization, concurrency control, audit logs, fraud monitoring, and reliable transaction management. Never use a classroom example as a real banking implementation.

```python
if total_days <= 0:
    print("Invalid total working days")

elif present_days < 0 or present_days > total_days:
    print("Invalid present days")

else:
    percentage = (present_days / total_days) * 100

    print("Student:", student_name)
    print("Attendance:", percentage, "%")

    if percentage < 75:
        print("Attendance Shortage")
    else:
        print("Attendance Satisfactory")
```

## **165. Design a Simple Software Application Workflow**

### **Definition**

A software application workflow is a structured sequence of activities that describes how users interact with an application and how the application processes information to produce the expected results.

A workflow helps developers understand the application before implementing its functionality.

It describes the movement of information from one step to another, including user actions, system operations, decisions, and outputs.

### **Why Is Application Workflow Design Important?**

- To understand application requirements.
- To organize development activities.
- To identify user interactions.
- To define application functionality.
- To understand data movement.
- To identify decision points.
- To reduce development mistakes.
- To improve communication between team members.

### **Main Components of a Software Application Workflow**

**1. User**

The person who interacts with the application.

**2. User Interface**

The screens, forms, buttons, and other elements through which users interact with the system.

**3. Input**

Information entered by the user.

**4. Processing**

The application performs calculations, validations, and business logic.

**5. Database**

Stores and retrieves application information.

**6. Output**

Displays the result to the user.

**7. Error Handling**

Manages invalid inputs, failed operations, and unexpected conditions.

### **Example: Simple Student Management Program**

```python
students = []

def add_student():
    student_id = input("Enter Student ID: ")
    student_name = input("Enter Student Name: ")
    student_age = int(input("Enter Student Age: "))

    student = {
        "id": student_id,
        "name": student_name,
        "age": student_age
    }

    students.append(student)

    print("Student Added Successfully")


def view_students():
    if not students:
        print("No Student Records Found")
        return

    for student in students:
        print("ID:", student["id"])
        print("Name:", student["name"])
        print("Age:", student["age"])
        print("----------------")


def main():
    while True:
        print("\nStudent Management System")
        print("1. Add Student")
        print("2. View Students")
        print("3. Exit")

        choice = input("Enter your choice: ")

        if choice == "1":
            add_student()

        elif choice == "2":
            view_students()

        elif choice == "3":
            print("Application Closed")
            break

        else:
            print("Invalid Choice")


main()
```

```text
Student Added Successfully
```

- A list stores student records while the program is running.
- The `add_student()` function collects and stores student information.
- The `view_students()` function displays saved records.
- The `main()` function controls the application menu.
- A loop allows users to perform multiple operations.

**Note:**
This is a beginner-level demonstration. The data is stored in memory and will be lost when the program closes. A real student management application would use a database, secure authentication, input validation, access control, and proper error handling.

# **Final Note**

Practical learning is where programming knowledge becomes real programming ability.

Students should not simply memorize definitions, algorithms, or programming syntax. They should practice identifying problems, understanding requirements, planning solutions, writing algorithms, drawing flowcharts, developing pseudocode, and converting their solutions into working programs.

Start with simple problems such as addition, multiplication, and checking even or odd numbers. Gradually move toward real-world applications such as banking systems, online shopping, attendance management, and student management systems.

**Remember:** Understand the problem → Identify the inputs and outputs → Design the algorithm → Create the flowchart → Write pseudocode → Develop the program → Test the result → Debug and improve.

This step-by-step approach builds the logical thinking and practical problem-solving foundation required to become a successful programmer.
