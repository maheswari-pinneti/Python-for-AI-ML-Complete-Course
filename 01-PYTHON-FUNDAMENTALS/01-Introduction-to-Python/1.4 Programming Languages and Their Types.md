# 1.4 Programming Languages and Their Types

## 44. What is a Programming Language?

### What is a Programming Language?

A programming language is a formal language used by developers to write instructions that a computer system can process and execute.

It provides rules, symbols, keywords, and syntax for expressing calculations, decisions, data operations, and other tasks.

Programmers use programming languages to create software such as websites, mobile applications, desktop applications, games, business systems, and artificial intelligence applications.

### Why Do We Use Programming Languages?

- To give instructions to computers.
- To solve problems using logical steps.
- To process and manage data.
- To automate repetitive tasks.
- To develop software and applications.
- To control devices and hardware.
- To build systems that communicate over networks.

### Main Elements of a Programming Language

1. **Syntax:** The rules for writing valid statements.
2. **Keywords:** Reserved words that have a special meaning in the language.
3. **Identifiers:** Names given to variables, functions, classes, and other program elements.
4. **Variables:** Named references used to work with values.
5. **Data Types:** Categories that describe the kind of data being used.
6. **Operators:** Symbols or keywords used to perform operations.
7. **Expressions:** Combinations of values, variables, and operators that produce a result.
8. **Statements:** Instructions that perform an action.
9. **Functions:** Reusable blocks of code that perform specific tasks.
10. **Control Structures:** Instructions that control the order in which code runs, such as conditions and loops.

### Example of a Programming Language

Python example:

```python
name = "Maheswari"
age = 23

print("Name:", name)
print("Age:", age)
```

Explanation:

- `name` and `age` are variables.
- `"Maheswari"` is a string value.
- `23` is an integer value.
- `print()` displays information.
- Python follows defined syntax rules to understand the instructions.

### Examples of Programming Languages

- Python
- Java
- C
- C++
- C#
- JavaScript
- TypeScript
- Go
- Rust
- Swift
- Kotlin

### Where Are Programming Languages Used?

| Area | Common Uses | Example Languages |
|---|---|---|
| Web Development | Websites and web applications | JavaScript, TypeScript, Python |
| Mobile Development | Android and iOS applications | Kotlin, Swift, Java |
| Desktop Development | Desktop software | C#, Java, C++ |
| Data Science | Data analysis and visualization | Python, R |
| Artificial Intelligence | Machine learning and AI systems | Python, C++ |
| Game Development | Computer and mobile games | C++, C# |
| System Programming | Operating systems and system tools | C, C++, Rust |
| Database Management | Querying and managing data | SQL |
| Embedded Systems | Software for electronic devices | C, C++ |

**Note:** A programming language does not directly make a computer understand human language. The language implementation, such as a compiler, interpreter, or runtime, processes the program so the computer can perform the required operations.

**Easy to Remember:** A programming language is a structured way for humans to write instructions that computer systems can process.

## 45. Why Do We Have Different Programming Languages?

### Why Are There Different Programming Languages?

Different programming languages exist because software projects have different requirements.

A language that is suitable for operating systems may not be the easiest choice for building a website. Similarly, a language that is useful for data analysis may not be the best option for programming a small embedded device.

Different languages are designed to provide different features, performance levels, development experiences, and ways of solving problems.

### Main Reasons for Having Different Programming Languages

#### 1. Different Types of Applications

Different applications need different capabilities.

Examples:

- Python is widely used in data science and automation.
- JavaScript is widely used in web development.
- C and C++ are used in systems and performance-sensitive software.
- Swift is used for Apple-platform development.
- Kotlin is commonly used for Android development.

#### 2. Performance Requirements

Some applications need very fast execution and direct control over system resources.

Examples:

- Operating systems.
- Game engines.
- Real-time applications.
- Embedded systems.

Languages such as C, C++, and Rust are often used in these areas.

#### 3. Ease of Learning and Development

Some languages are designed with readable syntax and developer productivity in mind.

For example, Python allows beginners to write useful programs with relatively little code.

#### 4. Hardware Control

Some languages provide low-level access to memory and hardware-related operations.

Examples:

- C
- C++
- Assembly language

These languages are useful when developers need detailed control over system resources.

#### 5. Application Size and Complexity

Large applications need features that support organization and maintenance.

Examples include:

- Classes and objects.
- Modules and packages.
- Type systems.
- Interfaces.
- Reusable libraries.

Languages such as Java, C#, C++, and TypeScript provide features that can help organize large software projects.

#### 6. Safety and Reliability

Some languages provide features that help prevent certain programming errors.

For example:

- Rust focuses strongly on memory safety.
- Java uses managed memory and runtime checks.
- TypeScript adds static type checking to JavaScript.

#### 7. Specialized Requirements

Some languages are designed for a particular problem area.

Examples:

- SQL for working with relational databases.
- R for statistical computing.
- MATLAB for numerical computing and engineering.
- Verilog for describing digital hardware.

### Can One Programming Language Do Everything?

A language can be used for many different purposes, but no single language is always the best choice for every project.

The choice depends on:

- Project requirements.
- Performance needs.
- Security and reliability requirements.
- Available libraries and frameworks.
- Developer experience.
- Platform and hardware support.
- Maintenance and long-term costs.

**Note:** Programming languages often overlap in their uses. Python, for example, can be used for web development, automation, scripting, and AI-related work.

**Easy to Remember:** Different programming languages exist because different problems require different tools and features.

## 46. Types of Programming Languages

### What Are the Types of Programming Languages?

Programming languages can be classified in different ways based on how close they are to hardware, how programs are structured, how code is executed, and what kinds of problems they solve.

There is no single classification that describes every language perfectly. A language can belong to several categories at the same time.

### Main Ways to Classify Programming Languages

#### 1. Based on Level of Abstraction

- **Machine-Level Language:** Instructions represented in binary form.
- **Assembly Language:** Uses symbolic instructions that correspond closely to machine operations.
- **High-Level Language:** Uses more human-readable syntax and abstractions.

#### 2. Based on Programming Style or Paradigm

- **Procedural Programming:** Organizes programs around procedures or functions.
- **Object-Oriented Programming:** Organizes programs around objects and classes.
- **Functional Programming:** Uses functions and emphasizes expressions and transformations.
- **Logic Programming:** Expresses problems using facts and rules.

#### 3. Based on Execution or Translation

- **Compiled Languages:** Commonly use a compiler to translate code into another form before execution.
- **Interpreted Languages:** Commonly execute code through an interpreter or runtime.
- Some languages use a combination of compilation and interpretation.

#### 4. Based on Type Systems

- **Statically Typed Languages:** Types are checked primarily before program execution.
- **Dynamically Typed Languages:** Types are associated with values and checked during execution.

#### 5. Based on Purpose

- **General-Purpose Languages:** Designed for many kinds of software development.
- **Domain-Specific Languages:** Designed for a particular problem area or domain.

### Examples of Language Classification

| Language | Common Classifications |
|---|---|
| C | High-level, procedural, compiled, statically typed, general-purpose |
| C++ | High-level, multi-paradigm, commonly compiled, statically typed, general-purpose |
| Java | High-level, object-oriented, compiled to bytecode and run on the JVM, statically typed, general-purpose |
| Python | High-level, multi-paradigm, commonly interpreted through a runtime, dynamically typed, general-purpose |
| JavaScript | High-level, multi-paradigm, commonly executed by an engine using interpretation and JIT compilation, dynamically typed, general-purpose |
| TypeScript | High-level, multi-paradigm, statically checked, commonly transpiled to JavaScript, general-purpose |
| SQL | High-level, declarative, domain-specific language for relational databases |
| Assembly | Low-level, processor-specific symbolic language |

**Note:** These categories are not mutually exclusive. For example, Python is both a high-level language and a dynamically typed language. C is both a procedural language and a compiled language in common use.

**Easy to Remember:** Programming languages can be classified by level, programming style, execution method, type system, and purpose.

## 47. Machine-Level Language

### What is Machine-Level Language?

Machine-level language, commonly called **machine language** or **machine code**, is the lowest-level form of instructions that a processor can execute directly.

It is represented using binary digits, 0 and 1. Each processor architecture defines its own instruction set and machine-code format.

### Characteristics of Machine-Level Language

- Uses binary digits (0 and 1).
- Executed directly by a compatible processor.
- Closely connected to the processor's instruction set architecture.
- Difficult for humans to read and write.
- Provides very low-level control over processor operations.
- Machine code for one architecture may not run on another architecture.

### Example of Machine Code

```text
10110000 01100001
```

This is an illustrative binary sequence. Its meaning depends on the processor architecture and instruction format.

### Advantages of Machine-Level Language

- Directly executed by the processor.
- Does not require a high-level language compiler at runtime for the machine instructions themselves.
- Allows precise use of processor instructions.
- Useful for understanding how processors execute instructions.

### Disadvantages of Machine-Level Language

- Very difficult to write and understand.
- Difficult to debug and maintain.
- Instructions are processor-specific.
- Large programs are time-consuming to develop.
- Small changes can be difficult to manage.

### Where Is Machine-Level Language Used?

- Processor instruction execution.
- Low-level system development.
- Firmware and hardware-related work.
- Compiler and assembler development.
- Computer architecture education.
- Reverse engineering and debugging at the machine-code level.

**Note:** Programmers generally write source code in assembly or high-level languages. Tools such as assemblers and compilers produce machine code.

**Easy to Remember:** Machine language is binary instruction code that a compatible CPU can execute directly.

## 48. Assembly Language

### What is Assembly Language?

Assembly language is a low-level programming language that uses short symbolic instructions, called **mnemonics**, to represent operations performed by a processor.

It is easier for humans to read than raw machine code, but it is still closely connected to a particular processor architecture.

### Characteristics of Assembly Language

- Uses symbolic instructions such as `MOV`, `ADD`, and `SUB`.
- Uses registers and memory addresses.
- Is generally specific to a processor architecture.
- Requires an assembler to translate it into machine code.
- Provides detailed control over processor operations.
- Is more difficult to write than most high-level languages.

### Example of Assembly Language

```asm
MOV R1, 10
MOV R2, 20
ADD R1, R2
```

This is illustrative assembly syntax. Exact instructions and operand formats depend on the processor architecture and assembler.

### How Does Assembly Language Work?

1. The programmer writes assembly instructions.
2. The assembler reads the source code.
3. The assembler translates the instructions into machine code.
4. The resulting object code can be linked if required.
5. The processor executes the resulting machine instructions.

### Advantages of Assembly Language

- Gives detailed control over processor instructions.
- Can be useful for performance-sensitive routines.
- Helps developers understand computer architecture.
- Useful in some embedded and hardware-related tasks.

### Disadvantages of Assembly Language

- More difficult to learn than high-level languages.
- Processor-specific.
- Requires more code for many tasks.
- Difficult to maintain for large applications.
- Development can take more time.

### Where Is Assembly Language Used?

- Embedded systems.
- Device drivers and low-level system components.
- Firmware.
- Processor and compiler development.
- Performance-sensitive routines.
- Computer architecture learning.

**Note:** Assembly language is not the same as machine language. Assembly uses readable symbolic instructions; an assembler converts those instructions into machine code.

**Easy to Remember:** Assembly language uses short symbolic instructions and an assembler converts them into machine code.

## 49. High-Level Programming Languages

### What is a High-Level Programming Language?

A high-level programming language is a language that provides abstractions and syntax designed to be easier for humans to read, write, and maintain than machine code or assembly language.

### Characteristics of High-Level Languages

- Readable syntax.
- Easier program development.
- Support for functions, modules, and data structures.
- Often provide large standard libraries and third-party packages.
- Generally less dependent on a particular processor architecture.
- Require a compiler, interpreter, or runtime to process and execute programs.

- Game development.
- Automation.
- Cloud applications.

**Note:** High-level does not mean that a language is always slow or less powerful. Modern compilers and runtimes can produce highly optimized programs.

**Easy to Remember:** High-level languages make programming easier by allowing developers to write instructions in a more human-readable form.

## 50. Procedural Programming Languages

### What is Procedural Programming?

Procedural programming is a programming paradigm in which a program is organized as a sequence of instructions divided into procedures or functions.

A procedure performs a specific task. The program calls these procedures in a particular order to complete a larger problem.

### Characteristics of Procedural Programming

- Organizes code into procedures or functions.
- Uses a step-by-step approach.
- Supports variables and data types.
- Uses conditions and loops.
- Encourages code reuse through functions.
- Often follows a top-down design approach.

### Common Concepts in Procedural Programming

1. **Sequence:** Instructions execute in order.
2. **Selection:** Conditions decide which instructions execute.
3. **Iteration:** Loops repeat instructions.
4. **Functions / Procedures:** Reusable blocks of code.
5. **Variables:** Store values used by the program.

### Example of Procedural Programming

Python example:

```python
def calculate_total(price, quantity):
    total = price * quantity
    return total

product_price = 100
product_quantity = 3

result = calculate_total(product_price, product_quantity)

print("Total:", result)
```

Explanation:

- `calculate_total()` is a function.
- It receives price and quantity as parameters.
- It multiplies the values.
- It returns the calculated total.
- The program displays the result.

### Examples of Procedural Languages

Languages commonly used for procedural programming include:

- C
- Pascal
- FORTRAN
- BASIC

Python can also be used in a procedural style.

### Advantages of Procedural Programming

- Easy to understand for small programs.
- Supports step-by-step problem-solving.
- Functions reduce repeated code.
- Makes program flow clear.
- Useful for learning programming fundamentals.

### Disadvantages of Procedural Programming

- Large programs can become difficult to organize.
- Shared data may be difficult to manage safely.
- Changes in one part of a program can affect other parts.
- Reusing complete program components can be harder than in some other approaches.

### Where Is Procedural Programming Used?

- Small and medium-sized applications.
- Utility programs.
- System programming.
- Embedded software.
- Algorithms and educational examples.

**Note:** Procedural programming is a programming paradigm, not an execution method. A procedural language can also be compiled, interpreted, statically typed, or dynamically typed.

**Easy to Remember:** Procedural programming divides a problem into smaller functions or procedures and solves it step by step.

## 51. Object-Oriented Programming Languages

### What is Object-Oriented Programming?

Object-Oriented Programming (OOP) is a programming paradigm that organizes software around **objects**. Objects combine data and the operations that work on that data.

A class is commonly used as a blueprint for creating objects.

### Main Concepts of Object-Oriented Programming

#### 1. Class

A class defines the data and behavior that its objects can have.

#### 2. Object

An object is an instance of a class. It contains data and can perform actions defined by its class.

#### 3. Encapsulation

Encapsulation groups data and related methods together and controls how internal details are accessed.

#### 4. Inheritance

Inheritance allows one class to reuse or extend features from another class.

#### 5. Polymorphism

Polymorphism allows the same interface or operation to work with different types of objects in different ways.

#### 6. Abstraction

Abstraction exposes important functionality while hiding unnecessary implementation details.

### Example of Object-Oriented Programming

Python example:

```python
class Student:
    def __init__(self, name, marks):
        self.name = name
        self.marks = marks

    def display_details(self):
        print("Name:", self.name)
        print("Marks:", self.marks)


student1 = Student("Maheswari", 90)

student1.display_details()
```

Explanation:

- `Student` is a class.
- `student1` is an object.
- `name` and `marks` are attributes.
- `display_details()` is a method.
- The object stores student information and provides a method to display it.

### Examples of Object-Oriented Languages

- Java
- C++
- C#
- Kotlin
- Swift
- Python
- Ruby

Many of these languages also support programming styles other than object-oriented programming.

### Advantages of Object-Oriented Programming

- Organizes code into reusable components.
- Supports encapsulation and abstraction.
- Can make large applications easier to maintain.
- Supports inheritance and polymorphism.
- Helps model real-world entities and relationships.

### Disadvantages of Object-Oriented Programming

- Can introduce unnecessary complexity for small programs.
- Requires understanding of classes, objects, and relationships.
- Poor class design can make software difficult to maintain.
- Inheritance can become complicated when overused.

### Where Is Object-Oriented Programming Used?

- Enterprise applications.
- Banking and business systems.
- Desktop software.
- Mobile applications.
- Game development.
- Large web application backends.

**Note:** A programming language does not have to be exclusively object-oriented. Python, JavaScript, and C++ support multiple programming paradigms.

**Easy to Remember:** Object-oriented programming organizes code around classes and objects that combine data and behavior.

## 52. Functional Programming Languages

### What is Functional Programming?

Functional programming is a programming paradigm that builds programs using functions and expressions.

It emphasizes transforming data through functions, avoiding unnecessary changes to shared state, and reducing side effects where practical.

### Main Concepts of Functional Programming

#### 1. Pure Functions

A pure function:

- Returns the same result when given the same inputs.
- Does not cause observable side effects.

#### 2. Immutability

Immutability means creating new values instead of changing existing data.

#### 3. First-Class Functions

Functions can be stored in variables, passed as arguments, and returned from other functions.

#### 4. Higher-Order Functions

A higher-order function accepts another function as an argument or returns a function.

#### 5. Function Composition

Function composition combines smaller functions to build a larger operation.

#### 6. Recursion

Recursion occurs when a function calls itself to solve a problem in smaller steps.

### Example of Functional Programming

Python example:

```python
numbers = [1, 2, 3, 4, 5]

squared_numbers = list(
    map(lambda number: number * number, numbers)
)

print(squared_numbers)
```

Output:

```text
[1, 4, 9, 16, 25]
```

Explanation:

- `numbers` is a list of values.
- `lambda` creates a small anonymous function.
- `map()` applies the function to each item.
- A new list stores the squared values.

### Examples of Functional Programming Languages

Languages strongly associated with functional programming include:

- Haskell
- Clojure
- Erlang
- Elixir
- F#

Languages that support functional programming features include:

- Python
- JavaScript
- Scala
- Kotlin
- Java

### Advantages of Functional Programming

- Encourages reusable functions.
- Can reduce unexpected changes to data.
- Makes certain programs easier to test.
- Helps developers reason about data transformations.
- Can support concurrent and parallel programming when designed appropriately.

### Disadvantages of Functional Programming

- May be unfamiliar to beginners.
- Recursion and function composition can be difficult at first.
- Some tasks may require a different way of thinking.
- Functional approaches are not always the simplest choice for every problem.

### Where Is Functional Programming Used?

- Data processing.
- Web application development.
- Concurrent systems.
- Financial calculations.
- Distributed applications.
- Applications that transform collections of data.

**Note:** Functional programming is a programming style or paradigm. A language can support functional programming without being exclusively functional.

**Easy to Remember:** Functional programming solves problems by combining functions and transforming data, often while avoiding unnecessary changes to existing values.

A scripting language is commonly used to write scripts that automate tasks, connect software components, control applications, or perform operations in a runtime environment.

Scripting languages are often designed to make automation and rapid development convenient.

### Characteristics of Scripting Languages

- Commonly run through an interpreter or runtime.
- Useful for automating repetitive tasks.
- Often provide libraries for file, text, and system operations.
- Can connect different software tools and services.

- Python
- JavaScript

- PowerShell

files = ["report.txt", "notes.txt", "summary.txt"]

for file_name in files:

### Disadvantages of Scripting Languages

- Large scripts can become difficult to maintain without good structure.
- Runtime dependencies may be required.

**Note:** A scripting language can also be a general-purpose language. Python and JavaScript are examples. The distinction between scripting and programming languages is not absolute.

**Easy to Remember:** Scripting languages are commonly used to automate tasks and make software components work together.

## 54. Compiled Languages

### What is a Compiled Language?

A compiled language is a language commonly used with a compiler that translates source code into another form before the resulting program is executed.

The output may be native machine code, object code, bytecode, or another intermediate representation, depending on the language and toolchain.

### How Does Compilation Work?

1. **Write Source Code:** The programmer writes code in a programming language.
2. **Compilation:** A compiler analyzes and translates the code.
3. **Object Code or Intermediate Output:** The compiler produces a target representation.
4. **Linking:** Required object files and libraries may be combined.
5. **Execution:** The program runs using a compatible processor or runtime.

### Simple Compilation Flow

```text
Source Code
    |
    v
Compiler
    |
    v
Object Code / Intermediate Code
    |
    v
Linking (if required)
    |
    v
Executable / Program Output
    |
    v
Execution
```

### Examples of Commonly Compiled Languages

- C
- C++
- Rust
- Go
- Swift

Java is also compiled, but commonly into bytecode that runs on the Java Virtual Machine rather than directly into a native executable in the usual workflow.

### Advantages of Compiled Approaches

- Errors can be detected before execution.
- Native compilation can provide high performance.
- The program can often run without the original source code.
- Some optimizations can be performed during compilation.

### Disadvantages of Compiled Approaches

- A compilation step is required.
- Build tools and configuration may be needed.
- Native executables may need to be built for different operating systems or processor architectures.
- Some errors can still occur at runtime.

### Where Are Compiled Languages Used?

- Operating systems.
- Desktop applications.
- Game engines.
- Embedded software.
- Performance-sensitive applications.
- Backend and cloud services.

**Note:** Compilation does not guarantee that a program will be fast or free from errors. Performance depends on the implementation, compiler, algorithms, hardware, and program design.

**Easy to Remember:** A compiler translates source code into another form, often before the program is run.

## 55. Interpreted Languages

### What is an Interpreted Language?

An interpreted language is commonly associated with an execution model in which a runtime or interpreter processes program instructions and carries out their operations.

Depending on the language implementation, the interpreter may work with source code, bytecode, or another intermediate representation.

### How Does Interpretation Work?

1. The programmer writes source code.
2. The language runtime reads or processes the code.
3. The runtime performs the required operations.
4. Results are produced while the program executes.
5. Errors may be reported when the relevant code is processed or executed.

### Examples of Commonly Interpreted Languages

- Python
- Ruby
- PHP
- JavaScript

These languages can have implementations that use compilation or Just-In-Time (JIT) techniques as well.

### Example of Python Code

```python
first_number = 10
second_number = 20

result = first_number + second_number

print(result)
```

A Python runtime processes and executes the program, then displays:

```text
30
```

### Advantages of Interpreted Approaches

- Convenient for experimentation and interactive development.
- Often supports rapid testing and modification.
- Many runtimes provide useful debugging tools.
- Can make cross-platform development easier when a compatible runtime is available.

### Disadvantages of Interpreted Approaches

- Some implementations may have additional runtime overhead.
- The runtime may be required on the target system.
- Some errors appear only when the relevant code is executed.
- Performance varies considerably between implementations.

### Where Are Interpreted Languages Used?

- Web development.
- Automation.
- Data analysis.
- Scripting.
- Rapid application development.
- Interactive programming and education.

**Note:** The terms compiled and interpreted describe common implementation approaches, not two perfectly separate groups of languages. A language may use both techniques.

**Easy to Remember:** An interpreter or runtime processes program instructions and executes them as the program runs.

## 56. Statically Typed Languages

### What is a Statically Typed Language?

A statically typed language is a language in which the types of expressions and values are checked primarily before the program runs, usually during compilation or a type-checking stage.

The type system helps determine what kinds of values can be used in different parts of a program.

### Characteristics of Statically Typed Languages

- Types are checked before execution in common implementations.
- Many type errors can be detected early.
- Variables, parameters, and return values may have declared or inferred types.
- Editors and development tools can provide useful type information.
- Type rules help describe how values can be used.

### Example of a Statically Typed Language

Java example:

```java
public class Main {
    public static void main(String[] args) {
        int age = 23;
        String name = "Maheswari";

        System.out.println(name);
        System.out.println(age);
    }
}
```

Explanation:

- `int` indicates that `age` stores an integer.
- `String` indicates that `name` stores text.
- The compiler checks whether the values and operations follow Java's type rules.

### More Examples of Statically Typed Languages

- Java
- C
- C++
- C#
- Rust
- Go
- Swift
- TypeScript (through static type checking)

### Advantages of Static Typing

- Helps detect many type errors early.
- Makes code contracts clearer.
- Improves editor support and code navigation.
- Can make large codebases easier to maintain.
- Helps developers understand expected data.

### Disadvantages of Static Typing

- Type declarations or annotations may add code.
- Type systems can take time to learn.
- Some changes require updating related type definitions.
- Strict type rules may feel restrictive to beginners.

**Note:** Static typing does not mean every variable must always have an explicitly written type. Languages such as Kotlin, Java, and Go can infer types in many situations. Static typing also does not prevent every runtime error.

**Easy to Remember:** Statically typed languages check types mainly before the program runs.

## 57. Dynamically Typed Languages

### What is a Dynamically Typed Language?

A dynamically typed language is a language in which type checking is performed mainly while the program is running.

In many dynamically typed languages, a variable name can refer to values of different types at different times.

### Characteristics of Dynamically Typed Languages

- Types are checked during execution.
- Variables often do not require explicit type declarations.
- A variable can refer to values of different types.
- Useful for quick experimentation and flexible development.
- Some type-related errors may appear only when code executes.

### Example of a Dynamically Typed Language

Python example:

```python
value = 100
print(value)

value = "Hello"
print(value)

value = 10.5
print(value)
```

Explanation:

- First, `value` refers to an integer.
- Next, it refers to a string.
- Finally, it refers to a floating-point number.
- Python determines the type of each value at runtime.

### More Examples of Dynamically Typed Languages

- Python
- JavaScript
- Ruby
- PHP
- Perl

### Advantages of Dynamic Typing

- Less need for explicit type declarations.
- Flexible during experimentation.
- Can make small scripts concise.
- Supports rapid development.

### Disadvantages of Dynamic Typing

- Some type errors appear only at runtime.
- Large projects may need additional testing and type-checking tools.
- Code can be harder to understand if values change type unexpectedly.
- Refactoring may require extra care.

**Note:** Dynamically typed languages still have types. The difference is mainly when and how type checking happens. For example, Python checks operations against the actual types of values at runtime.

**Easy to Remember:** Dynamically typed languages check types mainly while the program is running, and variables can refer to different types of values.

## 58. General-Purpose Programming Languages

### What is a General-Purpose Programming Language?

A general-purpose programming language is designed to solve many different types of programming problems rather than being limited to one specific application area.

Developers can use general-purpose languages to build different kinds of software, depending on the language's features and available tools.

### Characteristics of General-Purpose Languages

- Support a wide range of applications.
- Provide common programming features such as variables, conditions, loops, and functions.
- Often have large libraries and developer communities.
- Can be used with different frameworks and tools.
- May support multiple programming paradigms.

### Examples of General-Purpose Languages

- Python
- Java
- C
- C++
- C#
- JavaScript
- TypeScript
- Go
- Rust
- Ruby

### Where Are General-Purpose Languages Used?

| Application Area | Example Uses |
|---|---|
| Web Development | Websites, APIs, and web applications |
| Desktop Development | Business and productivity software |
| Mobile Development | Mobile applications |
| Data Science | Data processing and analysis |
| Artificial Intelligence | Machine learning applications |
| Game Development | Games and game tools |
| Automation | Repetitive task automation |
| System Software | Operating systems and utilities |

### Example: Python Used for Different Tasks

**1. Basic Calculation**

```python
a = 10
b = 20
print(a + b)
```

**2. File Handling**

```python
with open("notes.txt", "w") as file:
    file.write("Learning programming")
```

**3. Simple Data Processing**

```python
marks = [80, 75, 90]
average = sum(marks) / len(marks)

print("Average:", average)
```

These examples show how one general-purpose language can be used for different tasks.

### Advantages of General-Purpose Languages

- Flexible across different application areas.
- Large ecosystems of libraries and tools.
- Useful for learning broad programming concepts.
- Can support long-term application development.
- Developers can reuse their language knowledge across projects.

### Disadvantages of General-Purpose Languages

- May not provide the most specialized features for every domain.
- Some tasks may be easier with a domain-specific language.
- The best language still depends on the project requirements.

**Note:** General-purpose does not mean that one language is ideal for every application. Developers should choose a language based on the problem, platform, performance, and available tools.

**Easy to Remember:** A general-purpose language can be used to build many different kinds of software.

## 59. Domain-Specific Programming Languages

### What is a Domain-Specific Language?

A Domain-Specific Language (DSL) is a language designed to solve problems within a particular domain or area of work.

Unlike a general-purpose language, a DSL focuses on a specific set of tasks and provides syntax that is useful for that domain.

### Characteristics of Domain-Specific Languages

- Designed for a particular problem area.
- Uses terms and concepts familiar to that domain.
- Can make specialized tasks easier to express.
- Usually has a narrower purpose than a general-purpose language.
- May be embedded inside another language or used as a separate language.

### Examples of Domain-Specific Languages

#### 1. SQL – Database Queries

SQL is used to create, read, update, and manage data in relational databases.

Example:

```sql
SELECT name, salary
FROM employees
WHERE salary > 50000;
```

#### 2. HTML – Web Page Structure

HTML describes the structure and content of web pages. It is a markup language rather than a general-purpose programming language.

Example:

```html
<h1>Welcome</h1>
<p>This is my first web page.</p>
```

#### 3. CSS – Web Page Styling

CSS describes how web content should be presented.

Example:

```css
h1 {
    color: blue;
    font-size: 32px;
}
```

#### 4. Regular Expressions – Text Pattern Matching

Regular expressions describe patterns used to search, match, or replace text.

Example:

```text
^[A-Za-z]+$
```

This pattern matches a string containing one or more English letters from beginning to end.

#### 5. MATLAB Language – Numerical Computing

MATLAB is used for numerical computing, engineering, simulations, and data analysis. It is specialized for technical computing, though it is also a programming environment.

### General-Purpose Language vs Domain-Specific Language

| Feature | General-Purpose Language | Domain-Specific Language |
|---|---|---|
| Main purpose | Many kinds of problems | A particular domain |
| Scope | Broad | Specialized |
| Flexibility | Usually broad | Focused on domain tasks |
| Examples | Python, Java, C++ | SQL, regular expressions |
| Best suited for | Building different types of applications | Expressing specialized operations |

### Advantages of Domain-Specific Languages

- Make domain tasks easier to express.
- Use terminology familiar to domain experts.
- Can reduce the amount of code needed for specialized tasks.
- May improve productivity in their target area.

### Disadvantages of Domain-Specific Languages

- Limited to a particular area of work.
- May have smaller communities and ecosystems.
- Knowledge may not transfer directly to unrelated programming tasks.
- Complex tasks outside the domain may require another language.

**Note:** Not every specialized computer language is a general-purpose programming language. HTML is a markup language, CSS is a style-sheet language, and regular expressions are a pattern-description language. They are included here as examples of domain-specific languages and not as general-purpose programming languages.

**Easy to Remember:** A domain-specific language is designed to express tasks in one particular area, such as SQL for relational databases.

## 60. Programming Language vs Scripting Language

### What is a Programming Language?

A programming language is a formal language used to express instructions and logic for building software and solving problems.

Examples include:

- C
- C++
- Java
- Python
- JavaScript
- Rust

### What is a Scripting Language?

A scripting language is commonly used to write scripts that automate tasks, control applications, or connect different software components.

Examples include:

- Python
- JavaScript
- Bash
- PowerShell
- Ruby

### Difference Between Programming Language and Scripting Language

| Feature | Programming Language | Scripting Language |
|---|---|---|
| Meaning | Broad term for languages used to write programs | Common term for languages used to write scripts and automate tasks |
| Typical use | Building applications, systems, and software | Automation, task control, and application scripting |
| Program size | Can be used for small or large applications | Often used for small automation tasks, but can also build large applications |
| Execution | May be compiled, interpreted, or use a combination | Often executed through an interpreter or runtime |
| Performance | Depends on language, implementation, and application | Depends on language, implementation, and application |
| Examples | C, C++, Java, Python | Python, JavaScript, Bash, PowerShell |

### Are Programming Languages and Scripting Languages Different?

The terms are not completely separate categories.

A scripting language is also a programming language. The word *scripting* usually describes how a language is commonly used, rather than defining a completely different kind of language.

For example:

- Python is a programming language and is widely used for scripting.
- JavaScript is a programming language and is widely used to add interactivity to websites.
- Bash is a scripting language commonly used to automate command-line tasks.
- C is commonly used to build system software and native applications.

### Example: Python as a Programming Language

Python can be used to build a larger application:

```python
def calculate_average(marks):
    return sum(marks) / len(marks)


student_marks = [80, 75, 90]
average = calculate_average(student_marks)

print("Average:", average)
```

### Example: Python as a Scripting Language

Python can also automate a simple task:

```python
for number in range(1, 6):
    print("Processing item:", number)
```

The same language can be used in different ways depending on the task.

### When Should You Use a Scripting Language?

Scripting is useful when you need to:

- Automate repetitive tasks.
- Process files and folders.
- Run system commands.
- Perform simple data transformations.
- Connect different tools or services.
- Automate software testing and deployment.

### When Should You Use a General Programming Language or Compiled Toolchain?

A compiled toolchain or a language with specific system features may be suitable when you need to:

- Build performance-sensitive software.
- Develop operating-system components.
- Work close to hardware.
- Create large native applications.
- Meet specific memory or platform requirements.

**Note:** Do not choose a language based only on whether someone calls it a programming language or a scripting language. Consider the project requirements, available tools, performance, security, platform, and your team's experience.

**Easy to Remember:** Programming language is the broad category; scripting language is a common use-oriented label for languages used to automate tasks and control software.
