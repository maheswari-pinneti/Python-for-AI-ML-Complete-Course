# Chapter 1.6 – Programming Concepts in Real Life

## Learning Objectives

By the end of this chapter, you should be able to:

- Explain how programming is used in everyday life.
- Identify programming applications across different industries.
- Understand how software systems support banking, healthcare, education, commerce, transportation, and communication.
- Describe the role of programming in AI, machine learning, cybersecurity, robotics, cloud computing, and data analytics.
- Identify common inputs, processes, outputs, and examples in real-world software systems.
- Understand how web and mobile applications are developed to solve practical problems.

## 81. Programming in Everyday Life

Programming is used to build software that helps people perform tasks, access information, communicate, manage activities, and solve problems.

Many devices and services that people use every day depend on software created through programming.

**Examples:**
- Setting an alarm on a phone.
- Using a calculator.
- Ordering food online.
- Checking the weather.
- Using digital maps.
- Paying bills online.
- Watching videos.
- Sending messages.
- Tracking daily steps.

**How does programming help?**

A programmer writes instructions that tell a device or software application how to respond to user actions, process data, and display results.

**Example: Digital alarm**
- Input: Alarm time selected by the user.
- Process: The application checks the device's time and alarm settings.
- Output: The device triggers an alert when the configured time is reached.

**Why is programming useful in everyday life?**
- Automates repetitive tasks.
- Saves time.
- Provides information quickly.
- Connects devices and services.
- Helps people perform tasks more efficiently.

**Note:** Not every everyday device uses the same type of software or programming technology. Some systems run on a phone or computer, while others run on embedded hardware.

## 82. Programming in Banking Systems

Programming is used in banking systems to manage accounts, transactions, payments, customer records, authentication, and financial services.

Banks use software to process transactions and provide services through branches, websites, ATMs, mobile applications, and other channels.

**Examples of programming in banking:**
- Account creation and management.
- Balance checking.
- ATM withdrawals.
- Money transfers.
- Debit and credit card transactions.
- Online bill payments.
- Transaction history.
- Fraud monitoring.
- Loan processing.

**Example: Money transfer**

A transfer system may follow these steps:

1. A customer selects the recipient.
2. The customer enters the transfer amount.
3. The system validates the request.
4. The system verifies account and transaction rules.
5. The system processes the transfer.
6. The system records the transaction.
7. The system displays the result.

**Technologies that may be involved:**
- Backend programming.
- Databases.
- APIs.
- Authentication systems.
- Transaction-processing systems.
- Security and monitoring tools.

**Why is programming important in banking?**
- Processes financial transactions.
- Maintains account records.
- Supports digital banking.
- Helps detect suspicious activity.
- Automates financial operations.

**Note:** Banking software is highly sensitive. It must use appropriate security, transaction integrity, auditing, access controls, and reliability practices. A displayed success message alone is not proof that a transaction was safely completed.

## 90. Programming in Artificial Intelligence

**Artificial Intelligence (AI)** refers to a broad field of technology and research focused on building systems that perform tasks associated with capabilities such as reasoning, perception, language understanding, prediction, or decision-making.

Programming is used to develop AI systems, integrate models into applications, process data, and manage how AI features interact with users.

**Examples of AI applications:**
- Chatbots.
- Voice assistants.
- Image recognition.
- Language translation.
- Document analysis.
- Content generation.
- Search assistance.
- Decision-support systems.

**Example: AI chatbot**

1. A user submits a question.
2. The application receives the input.
3. The input is sent to an AI model or processing system.
4. The model generates a response.
5. The application receives and presents the response.
6. Additional rules may be used to validate, format, or manage the result.

**Programming technologies that may be used:**
- Python.
- APIs.
- AI libraries and frameworks.
- Backend systems.
- Databases.
- Model-serving infrastructure.
- Frontend applications.

**Why is programming important in AI?**
- Integrates AI models into software.
- Processes user input and data.
- Builds interfaces for AI systems.
- Automates workflows.
- Supports testing, monitoring, and evaluation.

**Note:** AI outputs may be inaccurate, biased, incomplete, or unsafe. AI applications require appropriate evaluation, monitoring, privacy safeguards, and human oversight where needed.

## 91. Programming in Machine Learning

**Machine Learning (ML)** is a branch of AI in which systems learn patterns from data to make predictions, classifications, recommendations, or other outputs.

Programming is used to collect and prepare data, train models, evaluate their performance, and deploy them into applications.

**Examples:**
- Spam detection.
- Product recommendations.
- Sales forecasting.
- Fraud detection.
- Image classification.
- Customer segmentation.
- Predictive maintenance.

**Example: Predicting house prices**

A machine-learning project may involve:

1. Collect house-related data.
2. Clean and prepare the data.
3. Identify features such as size, location, and number of rooms.
4. Select a machine-learning algorithm.
5. Train the model.
6. Evaluate the model.
7. Use the model to predict a price for new input data.

**Programming technologies that may be used:**
- Python.
- NumPy.
- pandas.
- scikit-learn.
- Matplotlib.
- Machine-learning frameworks.
- Databases and data pipelines.

**Why is programming important in ML?**
- Prepares and processes datasets.
- Implements training workflows.
- Evaluates models.
- Integrates models into applications.
- Automates predictions.

**Note:** Machine learning is part of AI, but not every AI system uses machine learning. A trained model's predictions depend on its data, training method, evaluation, and operating conditions.

**Programming and cloud technologies may include:**

## Important Terms

- **Software:** Instructions and related components that enable a computer or device to perform tasks.
- **Application:** Software designed to provide particular functions to users.
- **Database:** An organised collection of data.
- **API:** A defined interface through which software systems communicate.
- **Automation:** Using systems to perform tasks with reduced manual effort.
- **AI (Artificial Intelligence):** A field focused on systems performing tasks associated with capabilities such as perception, reasoning, language, or decision-making.
- **ML (Machine Learning):** A branch of AI that learns patterns from data.
- **Cybersecurity:** The practice of protecting systems, networks, applications, and data.
- **Cloud computing:** Providing computing services and resources over a network.
- **Data analytics:** Examining data to discover information and support decisions.
- **Frontend:** The user-facing part of an application.
- **Backend:** The server-side part that handles application logic, data, and services.
- **Automation workflow:** A sequence of tasks that a system executes or coordinates according to defined rules.
